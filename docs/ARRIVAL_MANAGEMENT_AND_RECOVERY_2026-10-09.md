# 취임 면담·한 화면 관리·경합 후 전개 — 2026-10-09

## 사용 흐름

- 첫 구단은 시작 버튼 뒤 짧은 취임 장면 두 개를 거쳐 실제 ClubStory의 구단주
  대화로 이어진다. 별도의 이야기 보기 버튼을 찾지 않아도 배경과 목표를 알게 된다.
- 취임 면담에서는 직접 두 번 답해야 한다. 선택은 기존 관계/대화 영수증으로
  저장하며 자동 답변은 없다. 면담을 끝낸 저장은 재접속 때 반복하지 않는다.
- 과거 조작 안내 완료 설정이 있어도 새 구단의 취임 이야기를 생략하지 않는다.
  면담 뒤 조작 안내는 건너뛰거나 설정에서 다시 볼 수 있다.
- 확정한 리그 라운드에 새 대화가 있으면 감독실에서 자동으로 연다. 가이드나
  다른 팝업을 덮지 않고 같은 라운드에서는 세션당 한 번만 제시한다.
- 홈·선수단·영입·유소년·대회 첫 화면은 업무 버튼을 중심으로 구성했다.
  구단주, 이야기, 기사, 훈련, 선수 관리, 재정, 대회 보고서는 공통 관리 팝업에서
  한 항목씩 연다. 제목·닫기·업무 선택은 고정하고 긴 보고서만 내부에서 스크롤한다.
- 기존 조작 노드를 팝업으로 옮겼다가 제자리로 돌려놓는다. 영입 필터와 8명씩
  표시하는 후보 목록은 함께 이동하며, 이름 없이 필터링하는 기존 기능을 유지한다.
- 개인 훈련에서는 중복된 18명 카드 목록 대신 선수 선택기와 선택한 선수의
  훈련을 먼저 보여준다. 홈은 실제 최신 기사 제목을 보여주고 전문은 소식 팝업에서 읽는다.

## 경합과 공격 종료

- 평상시 수비 접근 → 발을 뻗는 태클 → 흘러나온 공 경합 → 회수를 구분했다.
  공이 비어 있는 동안 소유자를 미리 확정하거나 해설로 회수 성공을 알리지 않는다.
- 2·4배속의 경합/회수는 최대 1배속으로 보여준다. 일반 패스는 선택한 배속을 사용한다.
- 차단·선방 이후에는 실제 수비수/키퍼가 공을 지킨 뒤 수비 동료에게 출발하는
  첫 패스를 보여준다. 소유자 없는 공이 다음 전개 위치로 미끄러지는 구간을 없앴다.
- 프리킥 수비벽은 키커보다 골문 쪽에 놓아 발에서 벽까지 공이 실제로 이동한다.
- 실제 하이라이트에 평상시 태클 상태가 남지 않도록 동작 상태를 분리했다.
  양 팀·일곱 공격 경로·장면 경계의 60fps 연속성을 확인했다.

경기 엔진·RNG·득점 확률·자금·기록·현재 저장 형식은 유지한다. 이 변경의 2D
경합은 표시용 동작이며 새로운 태클/선방 통계를 만들지 않는다. 계획 팝업은
경기를 정지하고 닫은 뒤 자동으로 재개하지 않는다.

## 검증

- 전체 125 suites / 931 checks 통과.
- PWA 14그룹, Android 자산/브리지 11그룹 통과.
- 필수 취임/구단주 선택/조작 안내 건너뛰기/완료 저장 재접속을 실제 브라우저에서 확인.
- 관리 팝업 열기·전환·닫기, 이름 없는 FW 영입 검색 후 전체 구단이 동일함을 확인.
- 320×568, 390×844, 844×390, 1366×900에서 취임 면담을 확인했다.
  선택 버튼은 최소 44px이며 창 자체는 스크롤되거나 화면 밖으로 나가지 않는다.
- 작은 세로/짧은 가로 홈의 주요 조작과 가로 넘침을 확인했다.
- 실제 첫 경기의 45·65·90분 전체 구단과 저장 복원이 독립 엔진과 일치한다.
  최종 1:0, 슈팅 3:2이며 결과 확정 뒤 재정·성장·다음 일정도 동일하다.
- 결과 확정 뒤 ‘주장이 남긴 훈련복’ 대화가 답변 없이 자동으로 열렸다.
  실제 새 기사 제목이 있는 320×568 홈의 여덟 버튼은 모두 화면 안에 있고,
  844×390 대회 메뉴의 마지막 버튼도 하단 탐색을 침범하지 않는다.
  최신 코드로 시작한 검증 탭의 브라우저 오류는 0건이다.
- Android 계측 시험도 새 필수 면담과 관리 팝업 흐름으로 갱신했다.
  APK 컴파일·에뮬레이터 성공 여부는 이 변경 커밋의 GitHub Actions에서 확인한다.
