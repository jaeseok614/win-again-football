# 세트피스 작전실과 두 사람의 골 — 2026-10-08

## 구현

전술 지시 상단 또는 경기 메뉴의 **세트피스 작전실**에서 코너 키커, 프리킥 키커, 공중볼 타깃을 함께 비교합니다. 현재 선수 얼굴과 전체 이름, 역할 지표, 체력, 우선 지정/대체 상태가 보입니다. 후보 목록은 현재 능력으로 정렬하며 킥오프 전 선택은 기존 Season.assignSetPiece/autoSetPiece를 사용합니다. 유효 저장, 선수 신원, 계약, schema/engine 10, 38/46경기와 저장 키는 그대로입니다.

영입 선수도 현재 선발이면 선택할 수 있습니다. 경기 중에는 현재 필드에서 엔진이 사용할 대체 선수를 읽기 전용으로 보여 줍니다. 교체·퇴장 때 제외되는 선수와 대체 순서는 엔진과 같습니다. 지정 자체가 RNG나 경기 시간을 소비하지 않고, 팝업을 닫아도 자동 재개하지 않습니다. 연습 지정은 연습 경기에만 적용됩니다.

역할 지표는 현재 능력의 가중치이며 성공 확률이 아닙니다. 360px 이하에서는 상세 가중치 식을 생략해 긴 선수 이름과 세 개의 44px 조작을 보존합니다. 역할 지표와 체력은 계속 보입니다. 저장 실패 시 성공이라고 표시하지 않습니다. 숨은 작전실은 계산하지 않고 같은 마크업은 다시 삽입하지 않습니다.

두 새 이야기는 완전한 확정 경기 기록에서 나옵니다.

- 깃발에서 골문까지, 둘의 약속: 실제 코너킥 득점자와 서로 다른 도움 선수, 득점 분수.
- 수비벽 너머에 남긴 이름: 실제 직접 프리킥 득점자와 득점 분수.

두 단계 선택과 관계 기록이 기존 ClubStory 영수증으로 남으며, 완료 후 작전실로 이어집니다. 미확정/부분 기록으로 이야기를 만들지 않습니다. 이야기 수가 늘어도 정상 저장을 거부하지 않도록 영수증 상한을 실제 열린 이벤트 수로 계산합니다. 중복 선택·위조 배우 검증은 유지합니다.
