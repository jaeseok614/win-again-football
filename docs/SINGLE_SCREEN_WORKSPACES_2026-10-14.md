# 가로 화면 통합과 짧은 핵심 관전 — 2026-10-14

경기장을 오른쪽 기록판보다 크게 표시한다. 가로 영역의 약 62%를 경기장에, 38%를 점수·점유율·실제 12기록에 사용한다. 기존 표시 경기장 1.6 비율보다 사용자의 새 비율 요구가 우선한다. 물리 월드 좌표/충돌/포메이션은 바꾸지 않는다.

핵심 관전은 반복되는 문전 공격의 표시 시간을 경기 5분당 5초까지 배정하고, 실제 슈팅은 항상 표시한다. 평상시 시간 진행 360배, 공격 6배, 슈팅 4.5배(선택한 관전 배속과 조합). 표시 요약은 전술 개요임을 명시하고 22명을 유지한다. 실제 기록을 줄이거나 결과를 미리 생성하지 않는다. 핵심 관전에서는 일반 선방의 별도 알림을 생략하며, 득점 그림은 2.6초 뒤 닫힌다. 일시 정지/하프타임/숨김/계획 팝업을 자동으로 재개하지 않는다. 전체 관전과 0.5/1/2/4배속도 유지한다.

같은 실제 경기의 모든 100ms 물리 틱으로 관전 배율 시간을 계산한 3개 표본: seed41 137→70초, seed73 159→77초, seed1632 210→105초. 득점/슈팅/유효한 저장 검증 유지. 약49~52% 감소이며 독서·하프타임·기기 처리시간을 제외한 관전 배율 추정이다. 모든 경기의 실측 종료 시간을 보장하지 않는다.

대회 기본 화면에 전체 24구단(1부20)과 선택 라운드12경기(1부10)를 동시에 표시한다. 표를 3열로 나누어 페이지를 없앤다. 휴대폰에서는 순위/구단/경기/득실차/승점과 선택 구단의 승무패·득실을 함께 표시하고, 1024px 이상에서는 표의 승무패·득점·실점 열도 표시한다. 라운드/구단 필터는 실제 조회만 하며 미래 점수는 —이다. 이전/우리 경기·기록/다음/큰 일정/시즌 기록 버튼은 하단 공통44px에 둔다. 컵은 실제7대진과 엠블렘 유지. 유럽 대회는 기존 DOM을 이동하여 실제 버튼 핸들러를 유지하고 대회 단계 필터를 사용한다.

유소년은 실제3후보의 종합/속도/지구력/성장한계, 맞교환 상대 선택, 주급·영입가·총지출·남는 자금을 함께 표시한다. 둘째 보고서가 생기면 완료된 탐색 버튼 공간에 보고서 필터를 배치한다. 전체 선수 능력과 계약 최종 검토는 기존 상세·검토 창을 사용한다. 새 창에서 실제 선수/금액/영입 제한을 보존한다. 전술 센터도 현재 주 키커를 본문에 표시하고 편집 버튼4개를 하단에 정렬한다.
