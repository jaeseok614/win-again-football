# 화면별 갱신 경계

`renderSeason()`은 메뉴·저장 상태·화면 표시를 갱신한 뒤 현재 화면만 구성합니다.
홈 대시보드와 선수 성장 표는 별도 함수로 분리했습니다. 순위, 지난 경기 요약,
선수 초상, 훈련 추천과 컵 대진을 숨긴 화면 때문에 계산하지 않습니다.

- 홈: 순위·일정·자금·건강·이사회 과제와 컵 요약만 표시합니다.
- 경기: 현재 상대 헤더·건강 요약과 경기 화면을 갱신합니다.
- 선수단: 선수 관리 / 훈련 / 기록 중 선택한 탭만 구성합니다.
- 영입·유소년·대회: 해당 화면의 후보, 장부, 대진을 구성합니다.
- 전술 분석: 경기 탭 선택을 갱신한 뒤 분석 탭이 실제 열려 있을 때 계산합니다.
- 열린 선수 상세 대화상자는 화면 경로와 별개로 최신 상태를 읽습니다.

다른 화면으로 이동하면 기존 일시정지 규칙을 그대로 적용합니다. 캐시된 모델이나
새 저장 필드를 추가하지 않았으므로 재진입 때 현재 경기 상태를 직접 사용합니다.
홈에서 경기장에 처음 들어올 때도 상대 이름·점수·선발·컨디션을 새로 구성합니다.

`test-visible-rendering.cjs`는 실제 캠페인을 사용해 7개 화면 경로, 라이브 10틱,
결과 확정 후 다음 일정, 타이틀 진입, 분석/건강/컵 계산 생략과 읽기 순수성을
검사합니다. 기존 경기 탭·전술 보드·훈련 UI 회귀 검사도 유지합니다.

검증: 82개 테스트 파일 / 763개 검증, 공개 PWA 14개 검증, Android 자산 생성,
360×640 실제 브라우저 메뉴 순회와 경기 시작→홈 이동→3분 일시정지 복귀 확인.
브라우저 오류 없음. 프레임률 또는 속도 향상 비율은 측정하지 않았습니다.
