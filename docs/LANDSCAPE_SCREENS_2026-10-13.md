# 가로 경기장과 읽기 화면 개선

사용자 피드백: 경기장이 너무 작고 세로용 안내를 가로로 옮기면서 여백이 커졌다. 가로 화면 안에서 그림, 긴 서사, 정보와 버튼을 함께 읽을 수 있어야 한다.

## 화면 변경

- 경기 점수판을 오른쪽 정보 열에 통합. 중계는 경기장 바로 위. 844×390에서 경기장 높이 140px → 243px(약74% 증가). 568×320에서는173px. 기존 일시 정지/속도/교체/전술 및 하단 메뉴 공간 유지.
- 안내6단계: 왼쪽 삽화, 오른쪽 본문, 아래 같은 위치의 이전/건너뛰기/업무 보기/다음. 취임과 복도 서사를 약300자로 확장하고 각 설명에도 실제 감독의 상황과 사용 방법 추가. 필수 취임 면담과 선택적 안내의 진행 규칙 유지.
- 대화: 왼쪽 장면 그림과 제목, 오른쪽 인물/본문, 질문 아래3개 선택지, 아래 이전/다음. 구단주·코치·주장 장면을 길게 보강. 질문에는 앞 장면 첫 문장을 다시 보여 맥락을 유지. 읽기만으로 대답이나 캠페인이 바뀌지 않는다.
- 수첩: 두 장의 그림/이야기 카드를 나란히 표시하고 아래 페이지 이동. 280px 높이에서는 미리보기만 한 줄로 줄이며 이야기 전체는 본문에서 읽는다.
- 전체 선수 버튼은 기존 전체 선수 목록 창을 직접 연다. 코치5직군은 작은 얼굴/계약 정보를3열로 표시(좁은 화면2열). 영입 필터와 선수 목록은 좌우로 배치. 유소년 그림 크기와 위치 기준을 수정하여 창 밖으로 영역이 번지는 문제 제거.
- 긴 영입 결과, 펼친 계약/훈련 보고서 및 작은 화면의 관리 상세는 내부 스크롤 유지. 모든 저장/경기 결과/물리 규칙은 그대로. 새 이미지 다운로드 없음.

## 검증

- 전체170 suites 실행:169 suites/1298 checks 성공, 취임 서사의‘5부 리그’표현 누락1개 발견. 문구 복구 후 해당 suite16checks 모두 성공. 합계170 suites/1314checks 통과(전체 재실행으로 표현하지 않음).
- 최종 관련 검사: 취임 안내10, 초상/용량10, PWA14, Android offline assets11. 서사 선택 및 저장 호환성 포함.
- Chrome 자동화:568×280,568×320,640×360,740×360,844×390,915×412,1024×768에서 경기장 최소 높이, 중계 위치, 안내6단계 전체 본문, 대화3페이지, 수첩/버튼 실제 영역 검증. 이전/다음 클릭, 대답 전후 단계, 전체 선수 진입, 키워드 없는FW필터 모두 성공.
