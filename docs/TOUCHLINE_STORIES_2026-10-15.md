각 장면은 기존 `listen / bold / practical`, `commit / honest` 두 단계의 명시적 대답을 사용한다. 이전에 선택한 두 문장을 다음 장면에서 다시 꺼내며, 세 번째 장면은 새로 추적하지 않을 출전·성과 약속을 만들지 않고 마무리한다. 컵·유럽 경기, 진행 중 점수, 일부 구간만 기록한 경기, 귀속되지 않은 득점이 있는 기록은 후속 장면의 두 경기로 세지 않는다. 다만 기존 연속 경기 검증기가 별도 자책골로 확인한 팀 득점은 완전한 경기로 세고, 일반 선수의 골로 만들지 않는다.

부상을 진단하거나 강제로 선수단을 바꾸지 않는다. 회복실 삽화는 대화의 장면이다. 실제 몸 상태는 기존 건강·선수단 화면에서 확인한다. 투자금·승점·영입·출전 시간은 이야기를 읽었다는 이유로 만들어지지 않는다. 완료 대화는 기존 StoryMood의 선수별 일시 반응 및 합계 ±2% 상한을 그대로 사용한다.

배우는 첫 확정 기록의 identity로 고정한다. 현재 선수단을 떠난 선수에게 새 면담을 억지로 열지 않는다. 이미 시작한 대답과 지난 시즌 기록은 유지한다. 기존 schema10, 저장 키, 시즌 전환 방식과 연속 경기 규칙1–9는 바꾸지 않는다.

## 가로 읽기와 이동

수첩의 ‘이어지는 이야기’에 현재 열린 장면·읽은 장면·기록 대기를 함께 표시한다. ‘도착한 이야기’는 현재 시즌만 담고, 과거의 미완료 장면도 ‘지난 시즌’에서 읽기 전용으로 보존한다. ‘남긴 대답’과 ‘지난 시즌’의 상단 시즌 필터로 원하는 기록을 바로 찾는다. 필터는 준비한 목록을 재사용하며 캠페인을 바꾸지 않고, 대화 복귀 시 선택한 시즌·종류·페이지를 함께 복원한다. 장면을 열면 왼쪽에는 삽화와 확정 근거, 오른쪽에는 장면·속마음·질문·대답이 나온다. 긴 문장은 문장·문단 단위로 읽을 수 있고 마지막 질문에서만 직접 답한다. 수첩에서 연 대화를 닫으면 보던 수첩 종류와 페이지로 돌아간다. 전술·선수단 바로가기를 명시적으로 고르면 해당 업무로 이동한다. 연속 사건의 마지막 반응에는 골키퍼→선수단, 출전 부담→건강, 원정→대회, 구단주→재정의 실제 업무 바로가기를 둔다. 이 버튼은 화면 이동만 하며 명단·출전·체력·돈을 바꾸지 않는다.

기자실은 기존 질문과 답변 문장을 유지하면서 추가 질문을 붙인다. 최근 리그 3연승/3연패, 재대결, 퇴장, 후보 득점, 멀티골, 무실점과 승부차기를 실제 확정 기록으로 구분한다. 과거 질문의 시점 뒤에 일어난 결과는 질문 근거에 넣지 않는다. 최근 세 경기의 원래 순서를 먼저 고른 뒤 전체 기록이 있는지 확인해, 부분 기록을 건너뛴 가짜 연승을 만들지 않는다. 이미 리그를 치렀지만 전체 기록이 없는 경우에는 첫 경기라는 질문 대신 확인 가능한 준비만 묻는다. 새 시즌 첫 기사에 지난 시즌 개인 기록을 현재 기록처럼 붙이지 않는다. 새 시즌 첫 질문은 지난 리그 기록을 다른 대회의 경험으로 잘못 부르지 않고, 지난 성적과 새 출발의 기준을 구분한다. 같은 시즌 컵 경험은 이번 시즌 경기 수로만 표시한다. 기존 구단 기사 본문과 저장된 기자 답변의 의미는 보존한다.

기자실의 기사 세 편·기록 필터·추가 질문·답변 버튼을 함께 배치한다. 홈 카드는 화면 크기만 달라질 때 재생성하지 않고, 짧은 질문 형식이 바뀌는 경계에서만 갱신하며 같은 기사·답변으로 키보드 초점을 복원한다. 기자실은 선택한 질문을 여는 순간 즉시 다시 그려 이전 질문이 남지 않게 한다. 화면에 마운트되기 전의 숨겨진 크기로 글자를 보정하지 않도록, dialog의 실제 열림 상태에서도 다시 측정한다. 전문 기사는 명시적인 긴 글 읽기 예외로 내부 스크롤을 쓰고 제목·닫기·복귀는 고정한다. 닫기·복귀 버튼은 안드로이드 기본 회색 외형 대신 게임 팔레트로 통일하고 실제 표시 색의 4.5:1 이상 대비를 확인한다. 기사 삽화의 장면 오버레이가 본문을 덮던 문제와 전문에서 그림이 음수 z-index 뒤로 숨던 문제를 실제 안드로이드 캡처로 찾아 수정했다. 훈련 운영 화면과 이야기·기억·현장 아틀라스는 각 원본 장면 비율(3:2 / 9:4 / 16:9)을 유지해 패널 안에 맞추며 이웃 장면이 섞이지 않는다. 좁고 긴 훈련 삽화에서도 사람을 가로로 누르지 않고 원본의 비율로 잘라 보여준다. 자산은 새로 복제하지 않는다. 1부 훈련 캠퍼스는 높이가 0이 되지 않게 별도 공간을 확보하며, 홈 경기장·캠퍼스도 원본 타일 비율로 표시한다. `source/browser/growth-proportions.cjs`는 별도 1부 검증 저장으로 여섯 가로 크기와 실제 하단 홈 버튼을 통한 홈 왕복을 확인한다. 높이 280px 이하에서는 장식 경기장만 생략하고 순위·승점·자금·가용 인원·다음 상대와 44px 조작 버튼을 모두 유지한다. 같은 최소 높이에서 기사 영역의 중복 표제·삽화를 줄여 세 제목이 눌리지 않게 하고, 기존 기자 버튼과 함께 실제 글자 경계를 검사한다.
