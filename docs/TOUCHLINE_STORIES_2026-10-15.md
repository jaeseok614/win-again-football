# 경기 뒤에 남는 말 — 2026-10-15

이번 작업은 하위 리그 감독의 성장이라는 차별점을 실제 경기와 연결한다. 승리한 감독의 독백만 반복하지 않고, 골문을 지키는 선수·계속 뛰는 선수·원정 팬·구단주가 같은 결과를 다르게 받아들이게 한다. 성적표와 인물의 사정을 함께 읽는 창작 서사다.

각 장면은 기존 `listen / bold / practical`, `commit / honest` 두 단계의 명시적 대답을 사용한다. 이전에 선택한 두 문장을 다음 장면에서 다시 꺼내며, 세 번째 장면은 새로 추적하지 않을 출전·성과 약속을 만들지 않고 마무리한다. 컵·유럽 경기, 진행 중 점수, 일부 구간만 기록한 경기, 귀속되지 않은 득점이 있는 기록은 후속 장면의 두 경기로 세지 않는다. 다만 기존 연속 경기 검증기가 별도 자책골로 확인한 팀 득점은 완전한 경기로 세고, 일반 선수의 골로 만들지 않는다.

부상을 진단하거나 강제로 선수단을 바꾸지 않는다. 회복실 삽화는 대화의 장면이다. 실제 몸 상태는 기존 건강·선수단 화면에서 확인한다. 투자금·승점·영입·출전 시간은 이야기를 읽었다는 이유로 만들어지지 않는다. 완료 대화는 기존 StoryMood의 선수별 일시 반응 및 합계 ±2% 상한을 그대로 사용한다.

배우는 첫 확정 기록의 identity로 고정한다. 현재 선수단을 떠난 선수에게 새 면담을 억지로 열지 않는다. 이미 시작한 대답과 지난 시즌 기록은 유지한다. 기존 schema10, 저장 키, 시즌 전환 방식과 연속 경기 규칙1–9는 바꾸지 않는다.

## 가로 읽기와 이동

수첩의 ‘이어지는 이야기’에 현재 열린 장면·읽은 장면·기록 대기를 함께 표시한다. 장면을 열면 왼쪽에는 삽화와 확정 근거, 오른쪽에는 장면·속마음·질문·대답이 나온다. 긴 문장은 문장·문단 단위로 읽을 수 있고 마지막 질문에서만 직접 답한다. 수첩에서 연 대화를 닫으면 보던 수첩 종류와 페이지로 돌아간다. 전술·선수단 바로가기를 명시적으로 고르면 해당 업무로 이동한다.

기자실은 기존 질문과 답변 문장을 유지하면서 추가 질문을 붙인다. 최근 리그 3연승/3연패, 재대결, 퇴장, 후보 득점, 멀티골, 무실점과 승부차기를 실제 확정 기록으로 구분한다. 과거 질문의 시점 뒤에 일어난 결과는 질문 근거에 넣지 않는다. 새 시즌 첫 기사에 지난 시즌 개인 기록을 현재 기록처럼 붙이지 않는다. 기존 구단 기사 본문과 저장된 기자 답변의 의미는 보존한다.

기자실의 기사 세 편·기록 필터·추가 질문·답변 버튼을 함께 배치한다. 화면에 마운트되기 전의 숨겨진 크기로 글자를 보정하지 않도록, dialog의 실제 열림 상태에서도 다시 측정한다. 전문 기사는 명시적인 긴 글 읽기 예외로 내부 스크롤을 쓰고 제목·닫기·복귀는 고정한다.
