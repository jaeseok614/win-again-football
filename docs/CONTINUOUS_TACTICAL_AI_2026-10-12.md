# 연속 엔진 version3: 전술 판단과 경기 균형

2026-10-12. 새 확인 킥오프와 새 전술 연습에 적용합니다. 시즌/match schema10, 저장 키, 앱 ID는 유지합니다. 이미 진행하거나 확정한 continuous version1/2와 spatial version1의 계산을 바꾸지 않습니다. 시즌을 자동으로 넘기지 않습니다.

## 개선한 실제 판단

- 공의 속도·마찰·높이로 짧은 도착 위치를 예측하고, 선수 속도·체력·전력질주 여력으로 도착 시간을 비교합니다. 단순히 현재 가장 가까운 선수를 고르던 압박을 바꿨습니다.
- 균형/로우 블록은 한 명이 경합하고 나머지는 위협 선수를 마크하거나 커버합니다. 가까운 미드필더가 도달할 수 있으면 마지막 수비선이 남습니다. 전방 압박은 두 명을 보내며, 로우 블록은 수비 폭과 높이를 줄입니다.
- 패스는 진전 거리, 받을 선수의 여유, 경로에 있는 수비수 도착 시간을 비교합니다. 방금 공을 준 선수에게 곧바로 되돌리는 연결은 낮게 평가합니다. 낮은 각도·수비 경로·압박을 읽어 슈팅을 선택하고, 실제 박스 안 주자가 있을 때 크로스를 비교합니다.
- 공 탈취 직후 역습 주자가 전력질주합니다. 패스 전에는 공/두 번째 수비수 기준 오프사이드 선을 지킵니다. 같은 쪽 풀백의 오버래핑과 뒤의 커버, 현재 배치의 역할을 사용합니다. 진영 교환 후 판단은 정확히 대칭입니다.
- 짧은 전력질주 여력은 빠르게 소모하고 커버/걷기 때 회복합니다. 장기 체력은 실제 이동 거리·강도·지구력으로 소모하며 이동 속도와 킥 정확도에 영향을 줍니다. 평균 체력, 교체와 기존 체력 게이지에 같은 값을 연결합니다.
- 뒤에서 무리하게 태클하는 대신 압박/커버를 유지합니다. 태클 재시도 대기와 공 접촉 가능 여부를 구분해 실패한 태클 뒤 수 초간 슛을 통과시키던 문제를 줄였습니다. 실제 접촉 높이에서 수비 몸 차단이 발생합니다.
- 골키퍼가 공을 몰고 오는 상대의 각도를 좁히고 가까운 공을 실제 접촉 뒤 확보합니다. 공 확보를 가짜 슈팅/선방 통계로 더하지 않습니다. 골문을 과도하게 비우지 않도록 전진 범위를 제한했습니다. 슛의 잡기/쳐내기와 세컨드볼도 같은 세계에서 이어집니다.
- 상대 감독은 늦은 열세/리드와 실제 체력에 따라 압박·역습·로우 블록을 고릅니다. 상대 보고서에는 실제 현재 지시를 표시합니다. 새 연속 경기의 코치 분석은 체력과 지시를 읽으며 옛 분 단위 기회 확률/가상의 속도 보너스를 예측치로 제시하지 않습니다.

팀 계획은 최대20명 목표를 5틱(0.5초)마다 갱신합니다. 소유 팀, 전술, 포커스, 수신자, 출전 인원과 진영 변화는 즉시 무효화합니다. 접촉은 여전히 매100ms 계산합니다. 캐시/전력질주 여력도 저장 재생 비교에 포함하며 변조를 거부합니다. 표시 배속, 일시 정지, 다시 보기, 앱 재실행은 다른 결과를 만들지 않습니다. 준비가 걸리는 연습/리플레이는 기존 로딩을 먼저 보여 줍니다.

## 비교 표본

재현: node source/measure-continuous-balance.cjs --version=3. 이전 규칙은 --version=2로 비교합니다. 개인 저장을 읽거나 파일로 내보내지 않고 고정된 새 경기 집계만 출력합니다.

동일6씨드(11/17/23/31/41/53), 새 토투넘 선발과 실제 첫5부 상대, 전술4개를 각각 끝까지 진행한24경기를 전후 비교했습니다. 교체/대화는 넣지 않았고 실제 추가시간을 포함했습니다. 득점/슈팅은 양 팀 합, 이동 거리는 우리 필드 선수 평균입니다.

| 전술 | v2 슈팅 → v3 슈팅 | v2 이동 → v3 이동 | v3 득점 | v3 종료 체력 |
|---|---:|---:|---:|---:|
| 균형 | 33.0 → 28.5 | 19.65km → 13.78km | 4.83 | 68.6 |
| 전방 압박 | 38.0 → 36.8 | 21.84km → 14.32km | 8.17 | 65.9 |
| 빠른 역습 | 40.7 → 45.5 | 21.18km → 13.95km | 9.50 | 66.6 |
| 로우 블록 | 39.8 → 25.8 | 20.99km → 11.99km | 3.67 | 71.8 |

출발 구단의 공격수와 첫5부 상대 전력 차이가 큰 표본입니다. 역습/압박은 여전히 높은 득점 편향을 보이며 이후 더 많은 상대/능력/교체 표본으로 조정해야 합니다. 수치가 실축구 리그 전체의 평균과 일치한다고 주장하지 않습니다. 목표 득점이나 슈팅 상한을 넣어 결과를 강제하지 않았습니다.

별도로 양 팀 모든 능력60/시작 체력95,4씨드(41–44), 전술4개를 실제96분씩 진행한16경기를 검사했습니다. 양 팀 합 득점은 균형1.0/압박2.5/역습3.0/로우 블록2.5, 슈팅은11.8/14.8/13.8/12.0입니다. 우리 점유율은49.3/54.6/45.4/47.8%, 양 팀 필드 평균 종료 체력64.2/63.0/63.6/64.3입니다. 전술 차이를 확인한 작은 고정 표본이며, 특정 전술의 승률 우위를 보장하지 않습니다. 특히 균형 운영의 슈팅/패스 성공률, 강한 출발 공격진의 득점 편향은 더 다듬을 범위입니다.

## 검증과 남은 범위

코드a98a03c의 전체158 suites/1191 checks는 로컬과 [소스 CI](https://github.com/jaeseok614/win-again-football/actions/runs/38197699617)에서 통과했습니다. 공개 PWA14/Android 오프라인11그룹, [Android14/15 실제 네이티브9/9·APK/AAB/lint](https://github.com/jaeseok614/win-again-football/actions/runs/38197699657)도 각각 성공했습니다. 생성 공개 파일과 원격 오프라인 자산 SHA256은 로컬과 일치합니다.

source/test-continuous-tactics.cjs는 실제 도착 시간, 압박/커버 인원, 진영 대칭, 배치 역할, 계획 캐시, 전환 침투/오프사이드, 안전한 연결, 실제 크로스 주자, 늦은 상대 지시, 체력/회복, 골키퍼 공 확보, 몸 차단, 새 저장 변조 거부와 공개v2 SHA256을 검사합니다. 기존 연속 회귀는 실제12포메이션, 명령/구간/리그·컵·유럽 정산, 부분 틱 복원과 동일 표시 속도 결과를 검증합니다. 연습v3은 정상 전개로 씨드4의75분 한 골 열세와 씨드7의80분 한 골 우세에 도착합니다. v1/v2 연습 씨드는 유지합니다.

팀 판단과 공중 궤적은 가벼운 휴리스틱입니다. FM 수준의 전술 학습/정밀3D 신체 충돌, VAR, 정교한 파울 어드밴티지, 부상 접촉 모델과 모든 IFAB 예외는 아직 없습니다. 현재 최대4명 퇴장 제한도 유지합니다. 이번 변경으로 모든 한계를 해결했다고 주장하지 않습니다. 실제 저사양 휴대폰의 긴 경기 체감/배터리와 다양한 능력·상대·날씨의 대규모 경기 균형은 계속 검증할 범위입니다. 최종 로컬/브라우저/공개 PWA/Android와 새 코드 CI 결과는 HANDOFF 첫 항목을 확인하세요.
