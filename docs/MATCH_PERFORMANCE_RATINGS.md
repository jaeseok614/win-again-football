# 경기 평점 (2026-10-07)

경기 기록 팝업에서는 진행 중인 선수별 평점을, 종료 리뷰에서는 최고 평점과 전체 출전 선수의 평점을 보여준다. 평점은 표시 전용이다. 선수 능력, 경기 RNG, 재정, 성장, 저장 형식과 시즌 결과를 바꾸지 않는다.

경기 중 평점은 실제 출전 시간, 골, 도움, 개별 슈팅·공격 장면, 카드, 실점과 무실점 기록을 읽어 계산한다. 경기 종료 뒤 확정 기록에는 개별 슈팅 장면을 보관하지 않으므로, 출전 시간·골·도움·카드·실점·무실점만으로 계산한다. 종료 화면은 이 차이를 설명한다.

동일 최고 평점이 있으면 한 명을 임의로 ‘맨 오브 더 매치’로 정하지 않고 공동 최고 평점으로 표시한다. 과거 저장에서 출전 선수 기록 자체가 없으면 평점을 만들지 않는다.

계산 범위는 3.0~10.0이며, 기본 출전 점수에 다음을 더하거나 뺀다.

- 출전 시간, 득점·도움, 실제 경기 중 슈팅 장면, 무실점은 가산한다.
- 포지션별 실점 영향과 경고·퇴장은 감산한다.
- 수치는 해당 경기의 기록을 읽기만 하며 경기 결과를 다시 계산하지 않는다.

평점 표는 경기 중에 숨겨진 화면을 매분 다시 만들지 않는다. 사용자가 기존 ‘경기 기록’ 팝업을 열었을 때만 계산하고, 팝업을 열면 경기는 기존 규칙대로 일시 정지한다.
