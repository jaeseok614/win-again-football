# 가로 한 화면 관리와 포메이션 직접 선택 — 2026-10-14

## 사용자 요구와 설계
포메이션 4-4-2·4-3-3 등을 선택할 때 새 팝업을 열지 않습니다. 전술 메뉴 첫 화면에 12개 포메이션, 11명 배치, 선택 선수의 6개 숫자/색상 능력치와 배치 종합, 23개 위치 선택, 공격·수비 지시와 세트피스 담당 3개를 함께 표시합니다. 일반 등록 포지션은 유지하고, 실제 동료의 배치 위치를 선택하면 두 선수의 좌표를 교환합니다. 포메이션 변경은 기존 정식 설정 경로를 사용합니다. 전술 코치 예상과 기본 능력/체력은 분리합니다.

선수단과 영입은 하단 메뉴에서 바로 한 화면으로 들어옵니다. 실제 명단/필터/계약 처리기를 재사용하며, 창을 복제하지 않고 원래 노드를 비모달 영역으로 이동했다가 복원합니다. 선수단은 실제 18명과 선택 인물의 전체 6개 기본 능력/컨디션을, 영입은 8명 후보와 현재 선수 비교/거래 검토 버튼을 함께 보여줍니다. 영입 GK·수비·중원·공격은 표시된 버튼으로 즉시 검색합니다. 상세 조건과 많은 기록 보고서는 별도로 열 수 있습니다. 주요 확인/영입/하단 메뉴는 44px, 사용자가 요청한 작은 직접 선택은 더 촘촘하게 배치합니다.

홈의 신뢰·훈련·현재 기자 질문·기사 요약은 첫 화면에 둡니다. 기사 요약에는 기존 원본 장면 이미지를 사용하고, 클릭/Enter 시 원래 본문을 생략하지 않는 전문과 실제 확정 기록의 문맥을 보여줍니다. 전문이 긴 기사는 내부 스크롤을 허용합니다. 언론사/인용은 게임의 가상 보도이며 실제 매체의 기사를 복제하지 않습니다. 읽기나 필터는 답변/지출/난수/경기 결과를 바꾸지 않습니다.

## 검증 범위
source/browser/dense-workspaces.cjs는 568×320부터 1280×720까지 8개 가로 크기에서 실제 하단 메뉴, 12개 포메이션 전체, 카드 내부 값/이름과 카드 겹침, 모든 선수/선택 속성/위치 버튼/키커 선택, 기사 그림·전문·키보드 닫기, 점유 위치 교환과 신원 보존, 필터 변경/장부 닫은 후 원래 화면 복귀를 검사합니다. Android 계측에는 실제 터치, 전문/선수 보고서 먼저 닫기, 비모달 화면의 뒤로가기, 직접 포메이션/자리 교환/키워드 없는 필터 검사를 추가합니다.
