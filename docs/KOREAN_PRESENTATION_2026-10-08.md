# 한국어 중심 화면 표기

한국 사용자에게 감독 생활을 자연스럽게 전달하도록 첫 화면, 감독실, 선수 성장, 영입과 계약 검토, 유소년, 라커룸, 기사, 이사회, 리그·대회·기록, 시즌 결산의 영문 제목을 한글로 바꿨습니다. 킥오프·경기 종료·선수 교체 안내도 한글로 표시합니다. 상위 리그의 목표와 기사는 “상위 6위”라고 안내합니다. 익숙한 축구 포지션 약어와 구단 방패의 짧은 코드는 유지합니다.

추가 생성 구단의 영어 이름을 한글로 표시하며, 상대 분석의 실제 참고 구단명에도 동일한 한글 표기를 적용합니다. 원본 참고 명단과 구단 ID·능력치·일정·난수·이적 신원·지난 기록은 바꾸지 않습니다. 기존 저장을 읽을 때 표시 이름만 새 표기로 읽습니다. 모든 116개 참고 이름의 한글 표기와 구단 ID·전력 보존, 읽기 전후 저장 및 복원 일치를 확인했습니다.

360×640 터치 브라우저에서 첫 화면→홈→선수단→영입→유소년→대회→경기→상대 보고서→홈을 직접 열고 저장 재접속까지 확인했습니다. 캠페인 전체 내용과 경기 난수는 그대로이며 오류가 없었습니다. 320×568부터 1440×900까지 8개 화면 크기에서 상대 선발 이름, 능력, 체력과 선발 비교 메뉴를 확인했고 가로 넘침이 없었습니다. 긴 명단과 상세 설명은 내부 세로 스크롤을 사용합니다.

실제 Android 휴대폰의 장시간 발열과 메모리 상태는 별도 확인이 필요합니다. 최신 커밋의 전체 소스/PWA 테스트와 Android 워크플로 결과, APK 링크는 PR 24에서 확인할 수 있습니다.
