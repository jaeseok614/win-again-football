# 세트피스 준비와 경기 반영

## 플레이 흐름

새 5부 토투넘 경기에서 전술·교체 창을 열면 코너 키커, 프리킥 키커,
코너 타깃을 킥오프 전에 고를 수 있습니다. 선수 능력 지표와 포지션을
함께 비교합니다. 한 선수에게 여러 역할을 줄 수 있습니다.

신규 경기 엔진 버전 8은 전체 기회 중 일부를 코너킥 또는 직접 프리킥으로
분류하고 경기 중계에 별도 장면으로 남깁니다. 코너는 키커 패스와 타깃의
공중볼 대체 지표(공격·수비·지구력), 프리킥은 키커의 공격과 패스를 반영해
슈팅 기대 득점을 계산합니다. 실제 슈팅·득점은 같은 경기 시드의 결정론적
난수로 정해지므로 역할을 바꿔도 난수 소비나 저장 복원 결과가 달라지지 않습니다.

선수가 교체되거나 퇴장해 지정 역할을 수행할 수 없으면 현재 필드에서
해당 역할 점수가 높은 선수가 이어받습니다. 현재 필드 선수가 골키퍼뿐이면
우리 팀은 세트피스 장면을 만들지 않습니다.

## 저장 호환

세트피스 지정은 경기 저장 객체에 포함되며, 새 토투넘 경기의 엔진 버전은
8입니다. 엔진 버전 1–7 경기에는 지정 필드를 추가하거나 과거 결과를 다시
해석하지 않습니다. 이전 캠페인의 리그·컵·챔피언스리그 일정과 저장 스키마는
그대로 유지합니다.

## 참고와 범위

[EA SPORTS FC 26 게임플레이 심층 노트](https://www.ea.com/games/ea-sports-fc/fc-26/news/pitch-notes-fc26-gameplay-deep-dive)는
공격·수비 코너 역할 지정과 세트피스 배치를 설명합니다. [EA SPORTS FC 26 기능 소개](https://www.ea.com/games/ea-sports-fc/fc-26/features)는
코너의 성공률을 현실 축구에 가깝게 조정하는 방향을 소개합니다. 이 게임에는
선택 가능한 세 역할과 가상 선수 능력에 근거한 간결한 확률 모델만 반영했습니다.
상대 수비의 세트피스 마킹 선택과 다양한 키커 전술은 아직 구현하지 않았습니다.
실제 구단·선수·언론사의 데이터나 사진은 사용하지 않습니다.
