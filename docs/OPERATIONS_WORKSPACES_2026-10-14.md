# 가로 훈련·구단 운영 화면

공식 Football Manager Mobile 자료에서 목록 옆에 선택 대상과 효과를 함께 놓고, 자주 사용하는 동작을 안정된 위치에 두는 방식만 참고했습니다. FM의 프로그램·계약 규칙이나 이미지·소스는 복제하지 않습니다.

- [공식 FMM2023 훈련 설명](https://community.sports-interactive.com/sigames-manual/football-manager-mobile-2023/training-r4936/): 선수 개요, 성장·역할·집중 프로그램을 함께 읽는 구조.
- [공식 FMM2023 인터페이스 설명](https://community.sports-interactive.com/sigames-manual/football-manager-mobile-2023/the-interface-r4928/): 일관된 작업·탐색 위치, 넓은 화면의 사이드바.

## 실제 구현

10개 운영 화면을 실제 관리 노드를 이동한 가로 페이지로 표시합니다. 홈의 주간 훈련/구단주 버튼, 선수단의 훈련/코치/몸 상태 버튼, 영입의 재정 버튼과 운영 사이드 메뉴를 모두 연결합니다. 경기·선수단·영입 등 전체 탐색은 동일한 아래쪽 메뉴를 유지합니다.

- 팀 훈련: 실제 18명 예상 능력·체력 변화, 평균 체력과 코치 효과, 종류 선택 및 명시적 실행. 이미 훈련했거나 대회 중이면 이유와 현재 18명 상태를 보여줍니다.
- 개인 훈련: 전체 18명, 이름/포지션 필터·정렬, 선택 선수의 실제 성장 한계·확정 출전 경험·체력·최근 경기·4프로그램의 효과와 비용. 숫자와 색상으로 주요 능력 비교. 전체 능력/인물 보고서만 상세 버튼 사용.
- 코치: 현재 5역할과 10후보, 실제 얼굴·이름, 주급/7경기 비용/부상 감소, 실제 영입·연장·해지 견적과 차단 이유. 후보 선택만으로 계약하지 않습니다. 원래 Staff 핸들러를 유지합니다.
- 구단주: 신임·신뢰·현재 약속과 진행, 4면담 주제·유소년 선택·최근 기록. 주제 선택 후에만 실제 면담 확정.
- 몸 상태: 실제 포지션별 가용/필요 인원, 부상·피로 명단, 최근 점검, 회복·선발 미리보기. 중복 설명을 줄이고 실제 제안/취소/적용 버튼을 보존합니다.
- 선발 계획: 3개 저장 슬롯과 이름/저장/미리보기, 현재 11명 또는 불러올 11명의 상태를 함께 표시. 미리보기와 적용 분리.
- 재정: 현재 자금·실제 전체 주급·최근 경기 순수익과 최근 6장부, 실제 리그 수입/보상 규칙. 미래 기본 계획은 전망임을 명시하며 긴 46라운드 내역만 선택해서 내부에서 읽습니다.
- 구단 현황·징계: 현재 시즌/구단 지표, 실제 대회별 경고·정지를 펼쳐 표시.

## 불변성과 검증

시즌/경기/연속 물리 버전, 저장키와 앱 패키지 유지. 읽기·필터·후보 선택·미리보기는 결과, RNG, 자금, 선수단을 바꾸지 않습니다. 실제 실행은 원래 Training/Staff/OwnerBoard/SquadPlans/H 계약을 사용합니다. 세로 모드 추가나 자동 시즌 전환은 없습니다. 삽화와 인물은 기존 오프라인 원본 아틀라스를 재사용합니다.

브라우저 source/browser/operations-workspaces.cjs는 568×320, 640×360, 740×360, 844×364, 844×390, 915×412, 1024×768, 1280×720에서 실제 홈·사이드 메뉴로 이동해 10페이지와 내부 글자/이미지/조작 경계를 검사합니다. 실행 후 훈련 공유 잠금, 실제 계약금·장부, 약속, 11명 계획, 부상/피로 및 선발 변경 미리보기도 검사합니다. 기존 선수단·영입·전술/기사 페이지 검사를 함께 유지합니다.

Android API34/35의 기존 13기능 검사를 유지하고 실제 운영 메뉴 터치·캡처·주간 훈련·계약·계획·뒤로가기 검사를 추가합니다. 로컬 자산 생성만으로 설치판이나 Android 실기 검증 완료를 주장하지 않습니다. 정확한 통과 결과/커밋/설치 APK는 HANDOFF 최신 항목에 기록합니다.
