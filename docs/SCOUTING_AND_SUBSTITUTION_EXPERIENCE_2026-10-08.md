# 상대 분석·선발 비교·리그별 서사

이번 연속 개발은 선수 얼굴/구단 성장 그림을 추가한 뒤, 실제 휴대폰 크기에서
경기 준비와 교체 결정을 읽기 쉽게 만드는 작업이다. 앞선 이미지와 승격 전환
검증은 [구단 성장·실제 플레이 기록](CLUB_GROWTH_AND_PLAYER_EXPERIENCE_2026-10-08.md)에 있다.

## 화면과 동작

- 상대 보고서 첫 부분에는 포메이션, 준비 시 전술 성향/진행 시 현재 지시,
  활동 선수 종합 평균과 체력 평균이 보인다. 그 아래 바로 11명 명단을 놓았다.
  퇴장 선수는 명단에 남겨 표시하고 평균에서는 제외한다. 이름·종합·속도·체력은
  작은 화면에서도 비교할 수 있다. 주능력과 지구력은 모바일에서 선수 이름 아래에
  표시하므로 속성 값을 없애거나 가로 스와이프에 숨기지 않는다.
- 요주의 선수/코치 전력 비교와 세트피스의 상세 설명은 명단 뒤의 펼침 영역에
  남긴다. 펼친 상태를 보존하고, 숨긴 보고서와 같은 입력의 재렌더는 읽기 모델을
  다시 호출하지 않는다. 킥오프의 단계 변경도 캐시를 무효화한다.
- 선발과 후보 모두 실제 현재 선수의 종합·체력·컨디션을 표시한다. 컨디션과
  체력은 다른 값이다. 컨디션은 게임의 신원/최근 기록/사기를 활용한 표시 계산이며,
  종합은 현재 능력의 포지션 가중치이다. 추가 경기력 보너스를 부여하지 않는다.
  교체 비교로 숨긴 벤치를 매 경기 틱마다 다시 생성하지 않고 동일 마크업도 재사용한다.
- 작은 세로와 짧은 가로의 경기 팝업은 7개 큰 탭 대신 44px 메뉴 선택기를 보여
  본문 공간을 늘린다. 다른 섹션을 열면 스크롤을 처음으로 돌리고 현재 선택기로
  포커스를 보낸다. 넓은 화면에는 기존 메뉴 버튼을 유지한다. 계획 화면을 열면
  정지하고, 닫아도 직접 재개해야 한다. 퇴장/부상/출전 정지, 교체 인원과 기회
  규칙은 바꾸지 않는다. 팝업의 자세한 명단은 내부 스크롤이며 경기 본문은 한 화면이다.
- 긴 시즌의 대화는 현재/당시 리그의 38·46경기와 공간 묘사를 따른다. 1부에서는
  승격이 아닌 TOP 6 목표와 상위권 경쟁을 말한다. 대화 키·발생 라운드·기존
  선택 기록·관계 수치·선수 약속은 그대로이고, 표시 대사만 해당 단계에 맞췄다.

공식 [FM26 Mobile 기능 소개](https://www.footballmanager.com/fm26/features/football-manager-26-mobile-new-features-showcase)와
[전술/선수 명단 화면](https://cdn.footballmanager.com/site/inline-images/ARS_TACTICS_IFB_16PRO_ENG_opt.jpg)을
보며 이름과 비교 수치가 우선 보이는 구성을 참고했다. 화면/게임 코드나 사진을
복제하지 않았다. 새 선수 얼굴과 경기장 그림은 앞선 기록의 원본 생성 자산이다.

## 검증

- 실제 터치 조작: 첫 안내 → 전체 18명 → 손헝민 상세 → 전술/대화 → 상대 명단
  → 킥오프 → 진행 중 정지 → 하프타임 교체 → 90분 → 결과 확정 → 다음 홈 →
  재접속. 107,411ms 관전, 1:0, 슈팅 3:2. 전체 경기 상태가 별도 엔진 실행과
  같은 하프타임 교체를 적용한 결과와 정확히 같았다. 저장도 동일하게 복원됐다.
  페이지 오류는 없었다. 빠르게 설정에서 관전했으며 물리 휴대폰 측정은 아니다.
- 별도 실제 버튼/선택기 검증: 320×568, 360×640, 390×844, 412×732,
  640×360, 844×390, 768×1024, 1440×900에서 상대 보고서/코치/세트피스를 열고
  전술↔상대를 선택기로 전환한 뒤 선발 f1→후보 f3을 탭했다. 준비 변경은 실제
  선발만 바꾸고 경기 교체 횟수는 0이었다. 상대 보고서 읽기는 구단 상태를 바꾸지
  않았다. 본문에 가로 넘침이 없고 핵심 정보와 첫 명단 행이 처음부터 보인다.
  모바일 상대 이름 13px, 선발 이름 12·13px, 선택 행은 최소 76px이다.
- 앞선 성장 검증의 여덟 크기/일곱 단계 경기 배치는 그대로 유지한다. 점수·시간·
  중계·핵심 기록·44px 두 줄 조작을 유지하며 자세한 모든 선수/기사를 첫 화면에
  동시에 넣었다고 주장하지 않는다.
- 회귀 검증에는 보고서 평균의 퇴장 제외, 전개한 분석 보존/숨긴 읽기 생략,
  킥오프 캐시 갱신, 현재 선수 능력/컨디션, 후보 부상/초기 선발 변경 제한,
  HTML 이스케이프/벤치 캐시/키보드 포커스, 메뉴 선택기의 종료 단계 제한,
  현재·과거 리그에 맞는 대사를 추가했다. schema/engine 10과 저장 키를 유지한다.
- 전체 **104 suites / 803 checks**, 공개 PWA **14그룹**, Android 자산/브리지
  **11그룹**이 통과했다. 새 Android 계측에는 상대 요약/명단 순서/읽기 크기와
  선발·후보 비교를 넣었으며, 원격 에뮬레이터의 결과는 아래 PR에서 구분해 기록한다.
