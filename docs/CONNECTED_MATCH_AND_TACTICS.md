# 연결된 중계와 전술 배치 — 2026-10-05

슈팅 진입 때 공을 선수 발밑으로 순간 이동시키던 문제를 수정했다. 마지막 표시 프레임을 고정해 350ms 공 회수, 350ms 전진 패스, 750ms 실제 슈팅/차단, 결과 표시와 재개 배급을 연결한다. 이벤트 중계는 엔진 결과만 사용하고 추가 슈팅/득점이나 RNG를 만들지 않는다. 상대 선수 이름은 상대 편성의 가상 선수다. 집계형 상대 기록에 실제 득점자 통계를 새로 만들지 않는다.

배치판은 popup에서만 조작한다. Pointer Events/capture와 touch-action:none으로 손가락/마우스 드래그를 지원하며 이동 미리보기는 저장하지 않는다. drop에서만 저장하고 취소하면 원래 배치로 돌아간다. 방향키로 2% 이동도 제공한다. 자연 등록 포지션과 전술 배치 포지션을 구분한다. 좌표에서 구한 배치 포지션은 표기와 2D 이동 라인에 적용한다. 등록 포지션/역할 적합도/동일 포지션 교체와 결정 영수증은 기존 방식 그대로다. 위치 이동 자체가 결과 확률을 새로 계산하지는 않는다.

공통 좌표로 442,433,352,4231,4141,451,4411,343,532,541,41212,4312를 제공한다. 선발은 각 포메이션의 자연 포지션 인원과 가용성 규칙을 따른다. 선택 시 사용자 직접 배치를 초기화하며 전술 지시/주 포지션 역할 변경은 배치를 덮어쓰지 않는다.

새 UI 구단의 토투넘 기본값을 유지하고 별도 토투넘 시작 버튼을 제거했다. 최초 시작에 감독실 오프닝과 구단주/손헝민 대화를 보여주며 실제 보고서·전술·대화 안내를 이어간다. 건너뛰기는 기기 설정으로 기억하며 설정 팝업에 다시 보기만 둔다. 홈의 가상 스토리는 첫 경기 전/초반/5경기/10경기/1부/종료 진행에서 계산한다. 보상, 결과나 실제 대화 기록을 추가하지 않는다.
