# 끊기지 않는 첫 조작 안내

FM26의 단계별 화면 설명과 다시 실행할 수 있는 튜토리얼을 참고했다.
공식 자료: https://www.footballmanager.com/the-dugout/mastering-fm26-ui
구현과 대사는 게임에 맞춘 원본이며 FM 이미지/코드는 사용하지 않는다.

이전에는 설명에서 실제 전술 창을 열면 다음 버튼이 없었고, 창을 닫아야만
다음 안내로 넘어갔다. 새 흐름은 선수단 → 전술 → 대화 → 경기 준비이다.
각 실제 화면의 footer에 현재 단계·짧은 할 일·이전·다음·건너뛰기를 둔다.
기존 footer 조작은 안내 중에만 숨기고 안내 종료/이탈 시 복원한다. 전술
화면은 일반 모드에서 footer를 숨기는 스타일이 있어 안내 중에만 예외를 둔다.

- 다음: 기존 보고서를 닫고 다음 설명으로 이동한다. 원래 close 이벤트가
  나중에 도착하거나 보고서를 다시 열어도 두 단계씩 넘어가지 않는다.
- 닫기/Escape(보고서): 같은 단계 설명으로 복귀한다. 선수 상세 닫기는
  선수단으로 돌아가며 안내 단계를 바꾸지 않는다.
- 이전: 이전 설명으로 돌아간다. 첫 선수단의 이전은 해당 설명으로 돌아간다.
- 건너뛰기: 안내 조작과 상태를 제거한다. 경기는 직접 시작/재개한다.
- 선수 대화: 선택하지 않아도 다음으로 진행할 수 있다. 선택한 경우 기존
  실제 반응만 적용하며 다시 안내를 열어도 중복 적용하지 않는다.
- 완료: 경기 화면으로 이동하지만 킥오프는 하지 않는다. 기존 설정의
  ‘처음 안내 다시 보기’를 유지한다. 새 구단의 필수 취임/구단주 면담은 유지한다.
- 선수 상세에서 개인 훈련으로 직접 이동하는 기존 경로는 안내를 벗어나는
  명시적 탐색이다. 그때 안내 footer도 정리해 이후 일반 명단을 숨기지 않는다.

안내 문장을 코치의 한마디와 화면에서 확인할 일로 줄이고 마지막 설명에
필수 상대 브리핑, 경기 속도, 자동 하프타임, 결과 확정을 연결했다.
선수단 내부 명단/능력 보고서의 기존 스크롤은 유지한다. 진행 버튼은 고정된다.
320×568,390×844,844×390,1280×720 전술 안내에서 body scrollHeight=clientHeight,
진행 버튼 최소44px. 가로에서는 설명과 조작을 한 줄로 배치해 전술판을 보존한다.

schema/RNG/게임 능력과 자금 변경 없음. 저장 호환과 이름 상시 표시 유지.
PWA 3,879,857바이트이며 기존 3,885,000바이트 예산 안에 있다.
