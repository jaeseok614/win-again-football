# 영입 탐색과 계약 검토

영입 시장은 포지션, 이름/유형, 현재 자금, 관심 선수로 필터링하고 지출/성장 한계/주요 능력으로 정렬합니다.
지출은 각 후보에게 선택한 실제 방출 선수의 Economy.quote이며, 자금 필터는 거래 가능 시점을 보장하지 않습니다.
이미 영입한 후보를 표시할 때는 실제 현재 성장 능력으로 정렬합니다. 필터는 화면 상태이며 저장하지 않습니다.

`season.transferPlans = {version:1, shortlist:[marketIdentity,...]}`는 선택적인 관심 목록입니다.
현재 시장의 8명만 저장하며 중복/알 수 없는 ID/다른 스키마는 restore에서 거절합니다.
선호만 저장하고 돈/주급/경기/RNG를 바꾸지 않습니다. 마지막 선호를 삭제하면 필드도 제거합니다.
다음 시즌과 정상 구단 JSON 이동에서 유지됩니다. 유소년 보고서는 관심 목록에 넣지 않습니다.

시장과 유소년 후보 버튼은 즉시 거래 대신 최종 검토 대화상자를 엽니다.
떠나는 선수의 identity/경험, 들어오는 선수, 실제 지출/주급, 등록될 선발/벤치를 보여줍니다.
검토는 실제 Season.recruit를 복사본에 적용하므로 경기·주간·팀 대화·출전 정지 제한을 공유합니다.
확정 전 전체 구단 fingerprint를 다시 확인하며 달라진 경우 재검토를 요청합니다.
확정 중에는 상태 표시를 먼저 그린 뒤 등록하고, 중복 버튼/닫기를 막습니다.
취소나 조회는 저장·이적·지출을 실행하지 않습니다. 새 선수의 경험은 0, 체력은 100입니다.

모바일에서는 자금 계획을 접어서 후보 필터에 빨리 접근하도록 했습니다.
닫기/필터/확정의 초점을 복구하고 44px 이상 터치 영역을 제공합니다.
숨은 시장은 계산/렌더링하지 않습니다.

앱의 동일 축구 아이콘 4곳은 app-icons.js의 원본 하나를 공유합니다.
이미지 픽셀/크기/출처는 유지하며 단일 실행 파일의 중복 base64를 약 143KB 줄입니다.
실제 생성된 PWA 안의 데이터가 원본 PNG와 바이트 단위로 같은지 테스트합니다.

검증: 77개 파일 / 741개 테스트, 공개 PWA 14개 검증, Android 에셋 생성 통과.
실제 모바일에서 필터 → 관심 → 검토 취소 → 확정 → 새로고침으로 이적/금액/관심 복원을 확인했습니다.
배포용 단일 HTML도 별도 브라우저에서 아이콘과 계약 화면을 확인했습니다.
APK/AAB/lint/에뮬레이터 검증은 해당 PR CI를 확인합니다.
