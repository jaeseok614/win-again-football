# 구단주 성격과 언론 사건

2026-10-11. 게임 속 원본 가상 사건을 기존 ClubStory의 두 답변 대화로 추가했다.

## 사건과 조건

| 사건 | 등장 조건 | 선택되는 인물/근거 |
| --- | --- | --- |
| 승격 축하 뒤의 마이크 | 실제 이전 시즌보다 상위 부로 명시적으로 진입 | 구단주 성격별 기자 질문 |
| 능력표 밖의 부담 | 완전한 리그 기록 4경기 | 실제 출전 선수 중 등록 프로필 역할 종합 최고 |
| 사진 한 장, 아직 모르는 이야기 | 완전한 리그 기록 8경기 | 실제 출전 선수 중 압박 대처가 가장 낮은 선수 |
| 감독보다 먼저 나온 인터뷰 | 완전한 리그 기록 12경기 | 구단주의 공개 발언과 감독의 입장 차이 |
| 가능성에 붙은 이적 제목 | 완전한 리그 기록 20경기 | 실제 출전 선수 중 등록 잠재력 최고 |

각 대화 완료 뒤 두 리그 경기가 실제로 확정되면 답변과 실제 출전 분을 기억하는 후속 면담이 열린다. 컵 경기나 일부만 기록된 경기는 등장 횟수를 채우지 않는다. 사건은 시즌별 조건에서 한 번씩 발생한다. 무작위 실생활 사건 생성은 아니다.

능력 근거는 재생/저장 검증이 가능한 불변 등록 프로필이다. 훈련 뒤 현재 종합과 구분해 문구에 표시한다. 현재 소속 선수를 대상으로 시작하고, 떠난 선수의 완료 기록은 보존하되 새로운 미답변 사건은 만들지 않는다. 과거 시즌은 실제 보관 기록과 해당 부를 사용한다.

## 구단주와 선택

캠페인 seed로 승부 우선형/선수 보호형/언론 주도형/재정 현실형 중 하나를 고정한다. 성격이 시즌 이동으로 바뀌지 않으며 기존 저장에 새로운 필드를 추가하지 않는다. 5부 지역 매체 → 4부 리그 전문 매체 → 3부 전국 스포츠 매체 → 2부 승격 경쟁 특집 → 1부 전국 방송으로 관심 범위가 바뀐다. 1부 승부 우선형 목표는 TOP 6이다.

3개 첫 답변과 2개 후속 답변을 직접 선택한다. 선택 전에 긍정/부정 결과나 경기 효과를 보여주지 않는다. 완료 후 실제 선수 성향에 따른 집중 상승/부담 인원과 적용 기간을 공개한다. 낮은 압박 대처의 선수에게 공개 대응이 부담이 되거나, 선수 보호형과 충성도에 따라 지지 반응이 달라진다.

기존 StoryMood의 관계별 최신 대화 우선/개인별 합계 ±2%/두 확정 리그 경기 뒤 만료/킥오프 고정 규칙을 사용한다. 진행 경기 중 대화는 현재 경기 집중을 다시 계산하지 않는다. 관계 점수와 기존 집중 시스템 외에 영구 능력치·계약·재정·부상·징계·경질 규칙을 변경하지 않는다. 기존 ClubLife의 경기 전후 인터뷰 기능은 그대로이고, 이번 사건 인터뷰는 ClubStory 대화에 속한다.

## 가상 사건의 표현

익명 사진의 시각·장소·경위는 미확인이다. 실제 인물의 사생활 정보나 확인된 위법·징계로 기록하지 않는다. 소문에서 벌금/부상/계약 변경을 만들어내지 않는다. 이적 제목도 실제 제안이나 이적 요청과 구분한다. 인물과 매체의 대사는 게임을 위해 직접 쓴 문장이다.

## 구현과 검증

- story-pressure.js: 순수한 성격/등장/인물 선정/성향별 추가 집중 함수.
- club-story.js/ui: 기존 v1 선택 영수증·재생·자동 도착·페이지형 팝업을 재사용. 승격 질문의 말하는 사람은 기자로 표시.
- story-mood.js: 사건 ID를 실제 기여/화면 설명 양쪽에 전달해 반응 인원이 일치하게 함.
- owner-board: 성격과 현재 언론 관심 범위 표시. 기존 약속과 투자 기준은 유지.
- test-story-pressure.cjs: 6그룹. 완전 기록 조건/역할 종합·성향 대상/두 선택/후속 실제 분/변조 거부/만료·상한/선수 이탈·과거 보관·실제 승격 검증.
- 전체 144 suites /1083 checks, PWA 14그룹, Android 오프라인 자산 11그룹 검증.
- 320×568, 390×844, 844×390, 1280×720에서 사건과 승격 질문의 대화 영역 스크롤 없음. 실제 5부→4부 저장에서 승격 기자회견과 선택 후 집중 상승 13명/부담 0명 확인. 버튼 최소 44px, 브라우저 오류 0.

최종 PWA 3,900,890바이트. shell 예산은 3,890,000→3,910,000으로 20KB만 늘리고 초상화 atlas 제한은 유지했다. 신규 원격 이미지/다운로드 없음. Android 자산 생성·검사는 네이티브 APK 컴파일 검증과 다르다.
