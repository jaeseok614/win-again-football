# 시즌 결산·일정·선발 계획

시즌 결산은 확정된 경기/선수 기록과 재정 장부를 읽기만 한다. 진행 중 경기나 승부차기 골은
선수 득점 기록에 넣지 않는다. 공동 선두는 모두 표시하며 임의의 MVP를 선정하지 않는다.
과거 시즌의 남아 있지 않은 경기, 성장, 자금은 추정하지 않는다. 성장은 현재 보유 선수의
이번 시즌 등록 당시 주요 능력과 비교한다. 리그 순수익은 선수 급여 차감 후이며 코치 급여는 별도다.

시즌 종료 버튼은 결산과 다음 시즌 승격/강등, 유럽 출전권, 이어지는 자금/성장 정보를 연다.
화면 확인만으로 시즌이 넘어가지 않는다. 시작 버튼은 처리 상태를 먼저 그린 뒤 한 번만
전환하고 실패 시 다시 시도할 수 있다. 시즌 결산은 대회 화면에서 이전 시즌까지 조회한다.

통합 일정은 기존 Season/Cup/Europe 대진과 결과에서 생성한다. 리그 → 국내컵 → 유럽 순서,
구버전 컵의 늦어진 라운드, 탈락 후 대진 제외를 반영한다. 다음 승자나 점수는 시뮬레이션하지
않는다. 조건부 토너먼트는 진출 시 예정으로 표시한다. 기본은 가까운 5경기이며 펼쳐 모두 볼 수 있다.
실제 날짜 대신 리그 라운드를 쓴다. 같은 라운드 전후 여러 경기를 선발 분배 시기로 안내한다.

선발 계획은 선수 identity 11명, 포메이션, 경기 지시와 24자 이내 이름을 3개까지 저장한다.
선택적인 season.squadPlans {version:1,slots:[]} 필드를 사용하며 없는 구버전은 그대로 유지한다.
저장/불러오기는 새 경기 준비 0분, 팀 대화 전에만 가능하다. 미리보기는 선발을 변경하지 않는다.
부상·출전 정지·이적된 선수는 제외하고 같은 포지션에서 체력/주요 능력 순으로 대체한다.
미리보기 뒤 훈련·선수·전술 등이 바뀌면 지문을 검증해 오래된 적용을 거절한다.
피치 수동 좌표와 개인 역할 표시는 포함하지 않는다. 삭제는 현재 선발을 바꾸지 않는다.
계획은 시즌 전환과 구단 JSON 내보내기/가져오기에 포함되고 RNG와 자금에는 영향을 주지 않는다.

검증은 실제 시즌 종료/전환/복원, 유럽 진출 및 컵 탈락 일정, 승부차기 점수 방향,
훈련 후 미리보기 무효화, 실제 출전 정지/영입, 잘못된 저장 거절, 공동 선두와 예전 저장의
누락 데이터, UI의 명시적 적용과 중복 클릭 방지를 포함한다. 브라우저 테스트는 별도 origin의
합성 구단 저장을 사용하며 개인 구단은 변경하지 않는다.
