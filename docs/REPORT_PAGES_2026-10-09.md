# 선수·전술 보고서 한 화면 구성 — 2026-10-09

기존 팝업 안에 긴 보고서를 넣는 것만으로는 작은 화면 문제가 해결되지 않았다.
선수 소개, 기본 능력, 세부 능력(필드 26개·골키퍼 24개), 포지션, 주발/컨디션, 역할, 기록, 성장과
평가 기준을 선택기로 한 항목씩 읽는다. 긴 능력 그룹은 여섯 항목 단위로 나눈다.
얼굴/이름, 닫기, 항목 선택, 이전/다음 선수는 본문과 별도로 유지한다.
상대 선수도 능력 비교/상태/유형/기준으로 나누며 실제 비교 선수 선택을 보존한다.

전술은 배치/팀 지시/선수 역할/특징/연결/세트피스/도움말/코치 조언으로 나눈다.
700px 고정 배치판을 남은 화면 높이에 맞췄으며 11명의 드래그 표적은 최소 44px이다.
12개 포메이션은 기존 선택기로 변경하고 중복된 12버튼 목록은 표시하지 않는다.
전술 분석은 전개 그림/상대 비교/전술 비교/확인 및 적용/코치 추천/기준으로 나눈다.
가로 화면은 내용을 좌우로 배치한다. 미리보기와 명시적 실제 적용은 그대로 분리한다.

기존 DOM 노드와 이벤트를 옮기므로 세부 능력 강조, 비교 선수, 전술 미리보기와
실제 적용 기능을 유지한다. 개인 훈련 이동은 해당 선수의 훈련 팝업을 직접 연다.
팝업을 다시 여는 동안 늦게 도착한 이전 close 이벤트가 새 내용을 비우지 못하게 했다.
캠페인·RNG·자금·훈련·전술은 페이지 조회만으로 변경하지 않는다.

## 검증 근거

- 320x568, 390x844, 844x390, 1366x900의 선수 페이지를 직접 순회했다.
  긴 골키퍼 이름을 포함해 작은 화면에 들어온다. 전술/분석은 작은 세로와 짧은
  가로의 모든 항목을 순회해 스크롤 크기와 실제 화면 밖 잘림을 함께 확인했다.
- 실제 구단의 보고서 열기/페이지 이동 전후 전체 season이 동일했다.
  전술 압박 미리보기 후 별도 적용 페이지의 선택 유지와 훈련 이동을 확인했다.
- 큰 글꼴 확대나 지원 크기보다 작은 창에서는 본문 스크롤로 내용을 계속 읽을 수 있다.
- 새 Android 계측 시험은 선수별 실제 세부 능력 항목 보존, 보고서 전체 페이지 높이,
  전술 11명과 분석 페이지 경계, 전체 구단 불변을 검증한다.
- 새 페이지 코드 약 20KB에 맞춰 번들 크기 회귀 상한을 3.65MB에서 3.68MB로 조정했다.
  얼굴 이미지 중복/아틀라스 크기 검사는 유지했다.

전체 회귀 검사와 최신 빌드 수치는 HANDOFF.md를 확인한다. APK/에뮬레이터 결과는
해당 커밋의 Actions에서 따로 확인한다. 개인 저장·화면·QA 자료는 저장소 밖에 둔다.
