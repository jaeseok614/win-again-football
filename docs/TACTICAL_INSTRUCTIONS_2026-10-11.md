# 포메이션 기본값과 직접 지시

포메이션 선택은 12개 기존 배치 중 하나로 선발을 정렬하고 해당 기본 공격·수비 지시를 적용합니다. 이후에는 감독이 9구역 드래그와 공격/수비 선택으로 조정합니다. 기본값 복원도 같은 명시적 동작입니다. 저장을 불러오거나 창을 열기만 해서는 기본값을 덮어쓰지 않습니다. GK 고정과 기존 경기 중 포메이션 변경 제한은 유지합니다.

추천 1–3은 기존 CoachLineup의 출전 가능 선수 최적 배치 평가입니다. 위치 적합도 70%, 주 능력 20%, 체력 10%를 비교하며 부상/정지 선수는 제외합니다. 창이 열렸을 때만 계산하고 입력이 같으면 재사용합니다. 추천 버튼은 비교 창을 열며 별도 확정 후 선발과 기본 지시를 적용합니다. 코치 추천은 기존처럼 경기 준비 중 팀 대화 전에만 가능합니다. 추천 점수가 승률이나 경기 능력 보너스는 아닙니다.

공격은 자유롭게/크로스 위주/돌파 위주/패스 연계, 팀 운영은 균형/전방 압박/역습/수비 위주로 독립 선택합니다. 우리 오픈플레이의 실제 action 분포만 변경하며 코너·프리킥과 상대 지시는 그대로입니다. 크로스 지시에서는 cross 62%, cutback 18%, through_ball 8%, dribble 4%, combination 8%; 돌파 지시는 12/12/12/52/12%, 패스 연계는 12/12/14/10/52%입니다. 이는 공격 기회가 발생했을 때의 선택 비율이며 공격 성공 확률이 아닙니다. 기존 action별 차단률·득점 계수와 중계 동작을 사용합니다. 수비 위주는 기존 lowBlock의 기회 감소 효과를 사용합니다.

optional match.attackInstructions는 {minute,focus} 기록 배열입니다. 같은 분 재선택은 마지막 선택 하나만 남기고 다음 분부터 적용합니다. 과거 장면 검증은 해당 분 직전 기록을 사용합니다. 공격 지시 선택/읽기는 RNG·시간·과거 결과를 변경하지 않습니다. 원래 v10 저장은 필드 없이 기존 동작을 유지합니다. 결산 후 optional plan.attackFocus를 다음 경기로 전달합니다. schema, 저장 키, 선수 정체성, 계약, 재정은 바꾸지 않습니다.

배치 페이지에 포메이션/추천/공격/수비/기본값 복원을 배치하고, 팀 지시 페이지는 여덟 선택과 현재 선택의 짧은 장단점만 표시합니다. 별도 보고서와 선수 상세 기능은 기존 페이지에 남깁니다. 계획 창을 닫아도 경기를 자동 재개하지 않습니다.
