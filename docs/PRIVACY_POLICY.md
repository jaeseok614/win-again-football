# 윈 어게인 · 축구 감독 개인정보처리 안내

시행일: 2026-10-02. Android 앱 `com.jaeseok614.winagainfootball`의 현재 오프라인
버전에 적용합니다. Google Play에 제출하기 전에 이 안내를 공개 웹 페이지로
게시하고 실제 출시 버전의 기능과 일치하는지 확인합니다.

윈 어게인 · 축구 감독은 가입이나 로그인을 요구하지 않는 오프라인 축구 게임입니다.
앱에는 광고, 결제, 분석 또는 추적 SDK가 없으며, 개발자가 운영하는 서버로 개인정보,
기기 식별자 또는 게임 진행 기록을 전송하는 기능이 없습니다.

## 기기에 저장하는 정보

구단과 선수 정보, 경기 진행, 전술, 대화·기사 기록 및 게임 설정은 현재 기기의 앱
내부 저장 공간에 보관합니다. 앱이 종료되거나 업데이트된 뒤 게임을 이어하기 위해
사용합니다. 개발자는 이 저장 정보에 원격으로 접근하지 않습니다. 자동 클라우드
동기화는 제공하지 않습니다.

## 사용자가 선택하는 저장 파일

사용자가 구단 파일 내보내기를 선택하면 Android 문서 선택기에서 고른 위치에 JSON
파일을 씁니다. 파일 불러오기는 사용자가 선택한 문서 하나만 읽고, 게임이 확인한 뒤
사용자가 교체를 누르면 구단에 반영합니다. 앱은 기기의 다른 문서를 검색하거나
사진·주소록·위치·마이크·카메라에 접근하지 않습니다.

문서 선택기에서 클라우드 저장 제공자를 고르면 사용자가 선택한 파일을 해당
제공자가 보관하거나 전송할 수 있습니다. 이는 제공자의 기능과 개인정보처리방침을
따릅니다. 앱 개발자 서버로 파일을 전송하지는 않습니다. 내보내기 중 잠시 만드는
앱 내부 임시 파일은 작업 완료·취소 또는 다음 시작 때 삭제합니다.

## 보관과 삭제

앱 내부 게임 데이터는 앱을 사용하는 동안 기기에 남습니다. Android 설정에서 앱
데이터를 삭제하거나 앱을 제거하면 내부 저장이 삭제됩니다. 사용자가 별도로
내보낸 파일은 앱 제거 후에도 선택한 위치에 남을 수 있으므로 해당 파일은 직접
삭제해야 합니다. 필요한 구단은 데이터 삭제 전에 내보내세요.

## 외부 링크와 변경

사용자가 직접 외부 HTTPS 링크를 누르면 기기의 브라우저로 열며, 방문한 사이트는
해당 사이트의 개인정보처리방침을 따릅니다. 향후 온라인 저장·로그인·광고 또는
분석 기능을 추가하면 실제 변경 사항에 맞춰 이 안내와 Play 데이터 보안 정보를
갱신합니다.
