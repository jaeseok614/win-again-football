# 슈팅 궤적·소유 전환·중계 속도 — 2026-10-09

사용자 피드백: 공격수가 찬 공이 키퍼에게 도착하는 느낌이 약하고, 탈취 후 공이
다른 선수에게 순간 이동하며, 평소 전개보다 중요한 장면이 급하게 끝났다.

## 수정

- 보통 속도에서 일반 패스의 이동은 약 1.485초에서 0.768초로 줄였다. 선수의
  발에서 출발해 받는 선수에게 이어지며, 12개 배치의 실제 측면 선수를 사용한다.
- 슈팅 비행은 0.55초에서 1.4초로 늘리고 공격수와 선방 위치의 거리를 벌렸다.
  슈팅은 일정한 방향으로 골문/키퍼에 접근하며 밝은 궤적을 남긴다. 선방 결과는
  공과 키퍼가 같은 위치에 도착한 뒤 나타난다. 득점은 골라인 밖의 골망에 도착한다.
- 2·4배속에서도 결정적인 컨트롤·슈팅·선방·골 순간은 최대 1배속으로 보여준다.
  공격 준비와 재정비는 최대 2배속, 일반 전개는 선택한 속도를 사용한다.
- 선수와 공의 장면 나이에 같은 최대 80ms 표시 간격을 적용했다. 느린 프레임의
  벽시계 경과를 한꺼번에 더해 슈팅이나 결과를 건너뛰지 않는다. 정지/숨김은
  장면 나이를 보존하고, 미표시 결과와 점수를 먼저 공개하지 않는다.
- 탈취하는 선수가 기존 공의 발 위치에 접근하고, 기존 소유자와 공을 사이에
  두고 만난 뒤 소유가 바뀐다. 이미 우리 공이면 접근 중 기존 소유자를 유지한다.
- 다시 보기의 추가 안쪽 좌표 변환을 없앴다. 실제 경기장과 같은 좌표이므로
  골이 박스 안에서 멈추지 않는다. 슈팅 선수 이름/강조와 키퍼의 별도 색을 보인다.
- 전술 전개 예시의 여섯 구간도 새 패스 시계에서 해당 소유자와 위치를 읽는다.
  해설 갱신은 현재 패스의 소유자/수신자에 맞춘다.

엔진·RNG·능력·확률·경기 결과·자금·저장 형식은 변경하지 않는다. 중계는
실제 기록된 이벤트를 표현하는 표시용 2D 장면이며 실측 위치 영상은 아니다.
별도 다시 보기의 0.5·1·2배속 선택은 기존처럼 사용자가 직접 조절한다.
