# 실제 이용자 테스트 안내

앱: 눈 떠보니 5부 리그 감독! 토투넘 1부 귀환기
개발: 이번생 게임즈 · 문의: jaeseok614@gmail.com

2026-10-21 오전11:29 KST에 무료 비공개 Alpha 1.0.0이 선택한 테스터에게 게시됐다. Play 참여 초대와 테스터 되기 버튼을 확인했다. 그룹 가입 뒤 같은 Google 계정으로 실제 참여·설치를 진행한다. 그룹 가입이나 자동 검사를 사람 테스트 완료로 세지 않는다. [심사·모집 기록](FREE_CLOSED_TEST_2026-10-21.json).

## 무료 테스트 참여 순서

1. [테스터 Google 그룹](https://groups.google.com/g/win-again-football-testers)에 가입한다. 회원 목록은 소유자만 볼 수 있다.
2. **같은 Google 계정**으로 [Play 테스트 참여](https://play.google.com/apps/testing/com.jaeseok614.winagainfootball)를 연다. 참여 자격이 반영되지 않으면 계정이 같은지 확인하고 잠시 후 다시 연다. 내부 테스트에 참여 중이면 먼저 해당 테스트에서 탈퇴한다.
3. 승인된 앱을 Play에서 설치하고 실제로 플레이하며, 참여 선택을 최소14일 연속 유지한다. 단순 그룹 가입은 Play 참여가 아니다.
4. 무료 자원 테스트로 사례비·상호 테스트 약속은 없다. 의견은 그룹이나 공개 지원 이메일로 보낸다. 개인정보나 저장 원본을 공개 댓글에 올릴 필요는 없다.

## 첫 실행에서 확인할 일

1. 휴대전화를 가로로 돌려 앱을 연다. 제목과 시작 버튼, 취임 이야기의 대사·선택지가 화면 안에 보이는지 확인한다.
2. 구단 홈에서 기사 요약·기자의 질문·감독의 속마음을 읽고 한 가지 답변을 고른다. 기사 전문은 요약을 누르면 열린다.
3. 선수단에서 전체18명과 체력·컨디션·종합을 확인한다. 한 선수를 골라 보고서를 열고 나이·주발·주급·포지션·능력치를 확인한다.
4. 전술 화면에서 포메이션을 바꾸고 선수를 빈자리와 동료 자리로 옮긴다. 동료 자리에서는 서로 위치가 바뀌는지, 배치 종합과 위치 표기가 겹치지 않는지 확인한다.
5. 경기 준비에서 우리와 상대 선발을 비교하고 킥오프한다. 경기장이 오른쪽 통계보다 넓은지, 중계·선수 이름·공·통계를 구분할 수 있는지 확인한다. 배속·일시 정지·교체를 직접 사용한다.
6. 득점 장면이 자동으로 닫히는지, 수동으로 멈춘 경기가 저절로 다시 시작하지 않는지 확인한다. 하프타임과 경기 종료 뒤에는 직접 다음 동작을 선택한다.
7. 앱을 닫았다가 다시 열어 진행 중이던 구단과 경기 기록을 확인한다. 저장·설치에서 구단 파일을 내보내고 별도로 보관한다. 불러오기는 현재 구단을 교체하므로 선택한 구단 요약을 먼저 확인한다.

한 번에 모두 마칠 필요는 없다. 다음 날에는 다른 전술·영입·훈련·기사와 면담을 사용해 재미와 불편을 기록하면 된다. 기기마다 글자 크기와 표시 속도가 달라 작은 화면에서도 직접 확인한다.

## 의견을 남길 때

- 가장 재미있었던 순간과 지루했던 순간
- 읽기 어려운 글씨·겹친 버튼·잘린 이미지가 있었던 화면
- 경기 속도, 선수 움직임, 공과 이름의 구분
- 오류가 난 순서, 기종과 Android 버전, 앱 버전
- 저장이 이어졌는지와 다시 실행하면 문제가 사라지는지

구단 저장 원본은 기기에 보관하고, 재설치 전에는 구단 파일을 먼저 내보낸다. 현재 직접 설치용 디버그 APK와 향후 Play 설치판은 패키지와 서명이 다르므로 구단은 JSON 파일로 옮긴다.

## 비공개 테스트 운영 기록

현재 콘솔의 개인 계정에는 실제 테스터12명 이상이 연속14일 이상 참여를 선택한 상태를 유지하는 요건이 표시됐다. 내부 테스트·자동 에뮬레이터·AI 경기 실행은 이 사람 수에 포함되지 않는다. 14일이 지나도 자동 공개되는 것은 아니며 테스트 내용과 개선 사항을 정리해 프로덕션 접근을 신청한다.

운영자는 실제 참여 시작일, 받은 의견, 재현한 문제, 수정 버전과 다시 확인한 결과를 기록한다. 자동 검사 결과와 실제 이용자 의견을 구분하고, 받은 적 없는 의견이나 참여를 만들어 작성하지 않는다.
