# 전반을 보고 후반을 결정하는 라커룸

FM26 Mobile 공식 자료의 경기 준비·코치 피드백에서 참고한 원칙은
‘기록을 읽고 감독이 다음 행동을 결정하는 짧은 흐름’이다.
https://www.footballmanager.com/fm26/features/football-manager-26-mobile-new-features-showcase
FM의 화면, 문구, 이미지, 코드를 복제하지 않았다. 이 게임에서는 기존 경기
중단점과 선수 성향별 대화, 전술 지시, 교체 기능을 연결한다.

전반의 마지막 연출이 끝나면 라커룸 작전 회의가 자동으로 열린다. 실제
스코어·슈팅·공격 기회·xG를 우리:상대 순서로 표시한다. xG는 추정임을 명시한다.
수적 열세 → 출전 중인 최저 체력 선수(65 미만) → 최근 15분 상대 슈팅 우세
→ 현재 스코어 순으로 코치 의견 하나를 제시한다. 슈팅에는 골을 포함하고,
추가시간을 포함한 현재 시점까지의 로그만 센다. 퇴장·벤치 선수는 체력
검토에서 제외한다. 교체 소진 시 교체 대신 전술 검토로 연결한다.

검토 버튼은 기존 대화/전술/교체 팝업만 연다. 대화를 미리 계산하거나 선택을
대신 적용하지 않는다. 실제 선택 후 반응은 기존 대화 화면에서 보며, 브리핑을
다시 열면 현재 하프타임 대화 완료와 실제 교체 수/남은 교체 수를 다시 읽는다.
전반 요약 및 상세 메뉴의 흐름 요약에서 재방문할 수 있다. 닫기/돌아가기는
하프타임을 유지하고, 경기 화면의 후반 시작만 경기를 진행한다.

읽기 모델은 RNG·스키마·영구 능력·점수·저장을 바꾸지 않는다. 대화와 전술의
기존 실제 효과 외에 별도 코치 보너스는 없다. 양 팀 이름 상시 표시도 유지한다.
320×568, 390×844, 844×390, 1280×720에서 스크롤 치수와 버튼 경계를 검증한다.
접근성 글자 확대/비정상적으로 작은 창에는 스크롤을 허용한다.

PWA 예산은 3,870,000 → 3,885,000바이트로 15KB만 늘렸다. 실제 결과는
3,875,225바이트(+7,822바이트). 이미지 추가 없이 모델·UI·스타일만 추가했고
기존 공유 얼굴 atlas와 마크업 크기 제한은 유지한다.
