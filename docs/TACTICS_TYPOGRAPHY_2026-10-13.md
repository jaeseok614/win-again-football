# 전술 화면 가독성 정리 — 2026-10-13

## 참고와 적용

[FM24 Mobile 공식 선수단·전술 소개와 화면](https://www.footballmanager.com/features/football-manager-2024-mobile-new-features-revealed)의 배치판/선수 정보 병렬 배치와 능력·적합도·컨디션 구분을 참고했습니다. 이미지 검색의 선수 능력 화면에서 확인한 숫자 중심 정보 밀도를 자체 UI에 적용합니다. 외부 그림이나 스킨은 포함하지 않습니다.

- 전술 카드의 점수·포지션·이름을 내부 두 행으로 정렬. 변화량은 오른쪽 상세 패널에 표시.
- 0–100 능력치와 배치 종합에 80 이상 초록, 65–79 노랑, 50–64 파랑, 0–49 주황을 사용. 숫자/막대/범례를 같이 표시하므로 색만으로 판단하지 않습니다. FM의 1–20 척도가 아닙니다.
- 코치 선발 / 제안, 세트피스 / 작전실은 명시적으로 두 줄. 한국어 문장은 단어 단위로 줄바꿈. 긴 이름은 상세 패널과 접근성 이름에서 보존하며 좁은 배치 카드만 줄임 표시.
- 제목은 입력칸처럼 포커스되지 않고 실제 선택 메뉴로 포커스 이동. 키보드 포커스 표시는 유지.
- 경기장 크기에 따라 카드 폭/높이 조정, 골키퍼 카드 앵커 보정으로 작은 화면의 수비수 겹침 방지. 실제 전술 좌표와 경기 물리는 변경하지 않음.
- 7개 가로 화면×12포메이션에서 카드 내부, 카드 간 겹침, 전체 선수 상세, 메뉴 글자 경계를 검사하는 재실행 가능한 Chrome 검사: source/browser/landscape-typography.cjs. PLAYWRIGHT_MODULE / CHROME_PATH로 설치된 도구 지정 가능.
