# 구단주 면담 — 2026-10-04

홈에서 선택적으로 진행한다. 리그 경기 시작 전 주간당 한 번이며 컵·유럽 경기에서는
면담할 수 없다. 새 캠페인/기존 저장 모두 신뢰 50에서 시작하고 첫 면담 때만
`ownerBoard` 기록을 만든다. 저장 키와 경기 RNG는 그대로 유지한다.

| 선택 | 조건과 효과 |
| --- | --- |
| 승점 약속 | 다음 리그 3경기 4점. 달성 신뢰 +8, 미달성 −5 |
| 유소년 약속 | 지명한 센터 출신 1군 선수에게 다음 리그 3경기 합계 90분. 달성 +10, 미달성 −5 |
| 선수 보호 보고 | 신뢰 변화 없이 방침을 기록. 진행 중인 약속도 유지 |
| 투자 요청 | 신뢰 60 이상, 미해결 약속 없음. 시즌당 한 번 £20,000 입금과 신뢰 −10 |

시즌 말에 2경기가 남으면 승점 3점/유소년 60분, 1경기가 남으면 승점 1점/유소년
30분을 약속한다. 목표를 일찍 채워도 기한 라운드의 경기 결과 확정까지 기다린다.
컵·유럽 출전 시간, 미확정 경기, 약속 이전 기록은 포함하지 않는다.

신뢰는 0~100으로 제한하며 저장된 신뢰 숫자나 달성 플래그를 믿지 않는다.
면담 선택과 확정 경기 통계를 순서대로 재계산한다. 선수 이적이 있어도 약속한
identity의 기록만 집계한다. 면담 당시 장부 위치에서 선수를 보유했는지 확인한다.
투자는 `owner-investment-<year>` 장부 항목과 면담을 일대일 대조하며 금액·시점·
신뢰 자격·중복 여부를 검증한다. 다른 재정/주급/이사회 과제 보상과 별개다.

면담·신뢰·투자 기록은 시즌을 넘어 유지한다. 구버전은 새로 복원된 통계가 시작된
이후의 리그 준비부터 약속한다. 과거 약속은 생성하지 않는다.

신뢰는 현재 투자 요청에만 영향을 준다. 감독 해임, 투자금 자동 반복 지급,
선수 보호 보고의 능력치 보너스는 구현하지 않았다.

검증: 실제 2시즌 진행과 복원, 승점과 유소년 분 집계, 컵 제외, 선수 이적,
마지막 라운드 기한, 변조·중복·미연결 투자 장부 거부, 읽기/RNG 불변,
숨은 화면 계산 생략, 중복 클릭 방지. 360×640 / 1280×900 브라우저에서
실제 면담 선택·저장 복원·버튼 크기·가로 넘침을 확인했다.
