# 리그 센터

홈의 `리그 순위 · 전 경기`, 상세 순위표의 전체 결과 버튼, 대회 화면의 리그 센터에서
현재 대회의 구단 수와 시즌 길이에 따라 38경기 또는 46경기 전체를 조회합니다.
새 커리어와 확장 가능한 5부 저장은 116개 구단 참고 풀의 확대 일정을 사용합니다.
1부는 20팀·38경기, 2~5부는 각 24팀·46경기입니다. 구형 8팀·14라운드 저장은
옛 캠페인을 복원할 때만 호환하며, 확장 대상 5부 저장은 같은 시즌을 보존한 채
확대 일정으로 이어집니다. 별도의 저장 필드는 없습니다.

라운드를 선택하면 그 라운드의 홈/원정 대진과 실제 결과, 해당 시점의 순위,
직전 라운드 대비 순위 변동과 최근 5경기를 표시합니다. 구단 이름이나 필터를
선택하면 그 구단 경기 1개와 최근 결과를 구단 관점으로 보여 줍니다.
득실·득점·영문 구단명 동률 규칙은 기존 `Season.standings()`와 동일합니다.

미래 라운드의 대진은 이미 확정된 일정만 사용합니다. 다른 구단 결과를 미리
시뮬레이션하지 않으며, 순위와 최근 흐름에는 조회 시점까지 확정된 리그 결과만
포함합니다. 국내컵·유럽 경기는 리그 승점에 들어가지 않습니다.
현재 경기의 라이브/90분 점수는 홈/원정 관점으로 표시하되 결과 미확정을 명시합니다.
첫 결과 전의 순위는 `—`로 표시합니다. 승점 차는 승격·잔류 확정 판정이 아닙니다.

우리 경기의 저장된 선수 기록이 있을 때만 상세 경기 기록 버튼을 제공합니다.
다른 구단 경기에는 저장되지 않은 득점자·카드·출전 정보를 만들어 넣지 않습니다.
이전 시즌 전체 리그 결과는 원본 저장에 없으므로 현재 시즌만 조회합니다.

화면을 열 때만 모델을 계산합니다. 경기를 진행하거나 RNG·자금·기록을 바꾸지
않습니다. 대화상자는 기존 작전 일시정지를 적용하며 닫으면 원래 버튼으로 초점을
돌립니다. 작은 화면의 순위표는 표 영역 안에서 가로 스크롤합니다.

검증: 전체 일정 결과와 순위 비교, 과거/미래 범위, 컵 배제, 원정 점수 방향,
구단별 최근 5경기, 1부 대진, 구버전 기록 누락, 읽기 순수성, 필터·초점·중첩 기록 조회.
기능을 추가한 당시에는 84개 테스트 파일 / 774개 검증과 공개 PWA 14개 검증을 통과했습니다.
360×640과 1280×900 실제 브라우저에서 확인했고, 2:2 종료 전후의 미확정 점수와
결과 확정 뒤 4경기 공개·승점 1 반영을 확인했습니다. Android 상태는 PR CI 참고.
