# 코치 선발 비교와 안전한 새 버전 열기

## 경기 준비에서 판단하기

FM 모바일의 경기 전 준비 및 교체 평가 흐름을 참고해, 선발·후보 창에서
`코치와 선발 · 포메이션 비교`를 열 수 있습니다. 별도의 경기 핵심 버튼을
늘리지 않습니다. 준비 단계에서 팀 대화 전에만 구성을 바꿀 수 있습니다.

- 익숙한 위치 우선: 세부 위치 적합도 70%, 실제 주 능력 20%, 체력 10%.
- 주 능력 우선: 적합도 20%, 실제 주 능력 70%, 체력 10%.
- 체력과 로테이션 우선: 적합도 40%, 실제 주 능력 20%, 체력 40%.

각 포지션의 출전 가능한 선수 조합을 모두 고려하는 작은 동적 계획법으로
중복 없는 11명을 선택합니다. 부상·정지는 제외하고 선수가 부족한 포메이션은
제안하지 않습니다. 12개 포메이션의 실제 현재 선수, 주 능력, 체력과 별도
컨디션을 읽습니다. 컨디션이나 적합도에 새 경기 보너스는 없습니다.

선수 얼굴·전체 이름·배치·익숙함과 세로 체력 게이지를 보여 줍니다. 선수
상세를 열어 판단할 수 있고, 세 기준과 모든 포메이션을 비교하는 동안 저장,
RNG, 자금은 변하지 않습니다. 변경 확인 후 별도 확정으로 적용합니다.
선수·전술·기준·포메이션·사용자 배치가 바뀐 검토는 적용하지 않습니다.
사용자 배치가 있으면 포메이션 기본 배치로 초기화됨을 검토에 안내합니다.
세트피스 담당을 동기화하고 기존 세 선발 계획, 신원, 계약, 훈련을 보존합니다.
연습 경기는 실제 구단 선발을 읽거나 바꾸지 않습니다.

4-3-3/4-3-1-2의 중앙 미드필더와 3-5-2/3-4-3의 윙백 좌표를 공유 배치에서
보완했습니다. 인원수, 12개 포메이션, 저장된 사용자 좌표와 엔진 10의 결과
계산은 유지합니다. 기본 좌표와 그에 따른 위치 설명이 정확해졌습니다.

## PWA 버전 변경

서비스 워커가 검증한 인라인 셸 SHA256과 열린 문서의 셸을 비교합니다.
현재 문서를 제어하는 서비스 워커의 완료 메시지만 새 버전 안내로 사용합니다.
다른 버전은 자동 새로고침하지 않고 `저장하고 새 버전 열기`를 제공합니다.
직접 누르면 경기를 정지하고 현재 구단을 저장한 뒤 새로고침합니다.
저장 금지·실패·연습 중에는 새로고침하지 않고 이유를 안내합니다.
준비가 끝난 기존 버전의 일반 완료 알림은 기존처럼 닫힙니다.
QA/오프라인 검사 쿼리에서는 서비스 워커 등록과 준비 알림을 생략합니다.

## 검증

- 전체 114 suites / 862 checks. 코치 모델 9그룹, UI 4그룹, PWA UI 8그룹.
- 공개 PWA 14그룹, Android 오프라인 자산/브리지 11그룹 통과.
- 코치 팝업 320×568, 360×640, 390×844, 640×360, 844×390,
  1365×900에서 창 경계, 가로 넘침과 44px 조작 확인.
- 실제 브라우저에서 세 기준 × 12개 포메이션 36개 제안을 비교했습니다.
  전후 전체 구단 JSON이 같고, 모두 11명과 가로 넘침 없는 명단을 확인했습니다.
- 실제 구단에서 4-3-3을 확정해 브레넌 존쏜이 데얀 쿨루셉스키를 대신했고
  평균 적합도 85→88, 체력 100입니다. 전체 적용 상태는 독립 모델과 같으며
  자금 £145,550·RNG를 보존했고 재접속의 전체 구단이 같습니다.
- 그 선발로 실제 90분을 관전해 1:2·슈팅 3:8, 하프타임 교체 1명/기회 0회,
  84분 두 번째 경고 퇴장을 확인했습니다. 전체 종료·결산 상태는 독립 엔진과
  같고 다음 리그 3R/자금 £142,600으로 복원됩니다.
- 열린 구 버전에서 실제 새 서비스 워커를 활성화해 업데이트 알림을 확인했습니다.
  명시적 버튼 뒤 문서 셸이 40b351…에서 ef9c51…로 바뀌고 전체 구단은 같습니다.
- 공개 3,546,622바이트. Android 3,546,015바이트, SHA256
  `9d68feef2d18372aa8f3c4525ff9003877f74bfcc3928f883e24016fc1714f0d`.

물리 휴대폰이나 이번 코드의 APK/AAB 결과는 확인하지 않았습니다.
개인/QA 저장과 스크린샷, 생성 Android 자산은 저장소에 넣지 않습니다.
