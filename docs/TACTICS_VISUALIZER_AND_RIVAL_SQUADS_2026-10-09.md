# 전술 전개 예시와 리그별 패러디 명단

## 전술을 눈으로 비교

FM26 공식 소유/비소유 전술 자료의 시각적 비교를 참고했습니다. 전술 분석의
기존 고정 개념도를 현재 선발·실제 상대 포메이션·사용자 배치를 읽는 예시로
바꿨습니다. 우리/상대 공 소유와 후방/중원/측면의 여섯 장면을 비교합니다.
실제 중계의 Movement.frame을 고정 시간에 읽으므로 새 전술 엔진이나 미래
경기 예측이 아닙니다. 양 팀 선수 번호, 공, 연결 선수 전체 이름, 배치 폭과
수비↔공격 간격을 표시하며 모두 표시용 예시임을 안내합니다.

준비·하프타임·작전 시간·정지한 진행 경기에서만 읽습니다. 퇴장 선수와
실제 교체 선수를 반영하고, 비교는 경기 지시·시간·통계·RNG를 바꾸지 않습니다.
선택 버튼의 키보드 포커스를 보존하고 숨은 화면은 모델 계산을 생략합니다.
연습이 실제 구단의 전술 계획을 읽거나 적용하는 경로도 막았습니다.

## 하위 리그 이름군

풋몹 공개 구단 명단의 포지션별 이름을 수동으로 참고해 원본 패러디 이름을
만들었습니다. 워킹·렉섬·샐퍼드·스톡포트와 아스널·맨체스터 시티·리버풀의
일곱 구단에는 별도 이름군과 요주의 선수를 제공합니다. 나머지 2~5부에는
하위 리그 참고 이름군을 사용해 세계적인 스타 이름이 임의로 섞이던 표현을
보완했습니다. 여러 시점의 참고 선수를 조합한 창작 명단으로 실시간 명단이나
특정 시즌의 실제 선발은 아닙니다.

상대 신원 opposition:club:index, 기존 능력치·컨디션·지구력·리그 전력·RNG와
유효 저장의 경기 결과는 유지합니다. 토투넘 sp_* 선수단도 유지합니다.
구단별 명단 배열은 공유 읽기 전용이며 외부에서 수정할 수 없습니다.
웹사이트의 실제 선수 사진·부상·시장가치·평점을 복사하지 않습니다.
