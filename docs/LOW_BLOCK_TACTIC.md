# 로우 블록 전술

킥오프 전 전술 분석과 경기 중 전술 선택에 네 번째 스타일인 로우 블록을 추가했습니다. 약한 팀이 강한 상대를 상대로 수비 간격을 좁혀 버티는 선택지를 제공하며, 전술 배치와 경기 엔진 결과에 같은 규칙을 사용합니다.

균형 운영과 비교하면 우리 찬스 생성률은 14% 낮고, 상대 찬스 생성률은 28% 낮습니다. 우리 수비 지표는 8% 높아져 상대의 슈팅 득점 확률도 낮아집니다. 추가 체력 소모는 없습니다. 전술판은 다음 실제 중단 시점까지의 찬스 지표와 선수 체력을 계산해 보여주며, 예상 스코어라고 표현하지 않습니다.

상대 공격 또는 중원 지표가 우리보다 크게 높으면 코치가 로우 블록을 제안합니다. 경기 중 한 골 앞선 상태에서도 강한 상대의 위협이 이어질 때 제안합니다. 뒤지고 있으면 기존 규칙대로 체력 상태를 확인한 뒤 전방 압박을 제안하고, 피로 경고가 있으면 휴식·교체 판단을 먼저 권합니다.

현재 저장 스키마와 RNG는 바꾸지 않았습니다. 기존 경기 버전 5·6과 기존 전술 결과는 그대로 읽습니다. 새 전술은 엔진 버전 7부터 허용되며, 새 5부 커리어에서 생성되는 경기가 버전 7을 사용합니다. 이미 진행 중인 버전 5·6 경기는 끝까지 이전 전술 선택지만 보여주고, 다음에 만들어지는 경기에 로우 블록이 나타납니다.

형태상 참고한 기능은 [Football Manager 26 Mobile의 새 전술 스타일 소개](https://www.footballmanager.com/fm26/features/football-manager-26-mobile-new-features-showcase)입니다. 설명과 효과 수치는 이 게임의 자체 전력·찬스 엔진에 맞춰 새로 정했습니다.
