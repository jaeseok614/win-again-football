# 공격 경로 분석과 연속 소유 전환 — 2026-10-09

## 플레이 변화

경기 기록 팝업에서 크로스·컷백·침투 패스·개인 돌파·패스 연계·코너·직접 프리킥의 실제 기회, 차단, 슈팅, 골을 우리/상대로 비교합니다. 골은 슈팅에 포함하며 모든 패스·크로스 시도나 성공률을 만들지 않습니다. 동률은 한 경로가 우세하다고 단정하지 않고 경로 미확인은 별도로 표시합니다. 현재 기록만 사용하므로 과거 확정 경기에는 저장하지 않았던 공격 경로를 덧붙이지 않습니다.

현재 배치에서 실제 넓게 선 윙어·풀백을 고르고, 상대에게 공이 넘어갈 때 두 선수가 공 주변에서 경합하고 회수한 뒤 다시 전개합니다. 배치 기준은 흔들리는 시각 좌표보다 먼저 고정하여 받는 선수가 임의로 바뀌지 않습니다. 기록된 슈팅 장면의 원래 선수와 구간도 유지합니다. 출전 정지 대체 선수의 실제 이름·신원을 보고서와 중계에 함께 연결했고 퇴장은 원래 슬롯의 카드로 제외합니다.

슈팅 장면이 끝나기 전 통계·선수 평점·공격 분석·타임라인·도전 진행에 결과가 먼저 보이지 않습니다. per-event xG가 저장되지 않으므로 재생 중에는 xG를 역산하지 않고 `장면 재생 중`으로 표시합니다. 마지막 장면의 도착 전 결과 확정과 종료 리뷰도 기다립니다. 빠른 생략과 동작 줄이기는 기존 즉시 표시를 따릅니다. 정지한 장면을 닫아도 자동 재개하지 않습니다.

해설은 전체 이름과 자연스러운 한국어 조사, 실제 키커·수신 선수·골키퍼를 사용합니다. 가상의 개별 상대 득점 기록이나 새로운 엔진 효과는 추가하지 않습니다. 모든 분석·애니메이션은 읽기 전용이며 schema/engine 10, RNG, 유효 저장, 경기 결과, 자금과 신원을 유지합니다. 숨은 분석은 계산하지 않고 같은 마크업은 다시 쓰지 않습니다.
