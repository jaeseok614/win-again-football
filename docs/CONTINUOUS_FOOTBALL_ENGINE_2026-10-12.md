# 전체 연속 축구 엔진 — 2026-10-12

## 실제 경기 상태

새 경기의 필수 선발 브리핑에서 킥오프를 확인하면 continuousSetup.version=2를 활성화한다. 전반·후반 전체를 100ms 고정 간격으로 계산하며, 68×105m 공간의 공과 실제 선발 22명이 같은 세계를 공유한다. 분당 기회 생성은 새 경기의 공격·득점 판정에 쓰지 않는다. 교체 선수도 현재 영입 선수의 등록 신원·능력·체력으로 들어온다. 상대는 브리핑에 나온 실제 11명의 개별 능력·체력·포메이션을 사용한다.

공은 소유권, 평면/높이 위치, 속도, 마지막 접촉과 비행 정보를 가진다. 패스 후 수신자가 다가가 실제 접촉해야 첫 터치/소유권이 생긴다. 공의 이동 선분을 검사하므로 빠른 패스가 수비수를 통과하지 않는다. 속도·가속·체력·역할에 따른 이동, 공 주변 압박과 먼 쪽 폭 유지, 합법 침투 대기, 윙 전진/크로스, 공중 헤더와 수비 걷어내기가 같은 계산에서 발생한다. 선수끼리의 겹침은 이동 목표의 완만한 분리로 줄인다.

슛은 실제 공의 방향·높이·속도로 날아간다. 골키퍼가 예상 도착점으로 움직여 닿으면 잡기/쳐내기가 생기며, 수비 접촉·골대/크로스바·굴절·세컨드볼이 다음 플레이로 이어진다. 골은 골 프레임 접촉을 먼저 확인한 뒤 골라인을 넘었을 때만 기록한다. xG는 슛 당시 거리·각도·압박·능력의 게임 내부 추정값이며, 득점 여부를 추첨하는 확률로 쓰지 않는다.

공이 나가면 마지막 접촉에 따라 스로인/코너/골킥을 준비한다. 실제 가까운 태클의 반칙과 카드, 페널티 구역 반칙, 프리킥/페널티킥, 두 번째 경고 퇴장, 패스 순간 공·두 번째 수비수 기준 오프사이드와 수신 순간 간접 프리킥이 연결된다. 세트피스 담당자가 공까지 걸어가고 상대가 보호 거리를 확보한 뒤 재개한다. 가까운 직접/간접 프리킥의 골키퍼는 골라인 예외를 사용한다. 직접/간접 프리킥 배달에는 오프사이드를 검사하며, 코너/스로인/골킥은 예외를 유지한다. 골 뒤에는 득점한 위치에서 다음 킥오프 자리로 이동하며, 하프타임의 진영 교환은 경기 중 이동과 구분한다.

전술은 실제 목표 수비선·압박 인원·패스 선택·전진/침투·폭에 적용한다. 기존 사기 및 StoryMood의 한시적 집중 효과도 실제 행동 능력에 적용하며, 영구 능력치를 바꾸지 않는다. 교체는 기존 5명/3창과 실제 추가시간 하프타임 경계 규칙을 유지한다.

## 화면과 시간

화면은 엔진의 현재 좌표를 읽고 인접 물리 프레임 사이만 보간한다. 표시가 결과나 RNG를 결정하지 않는다. 시계는 실제 계산된 분:초를 보여 주며, 추가시간도 실제 틱을 진행한다. 속도 선택 0.5/1/2/4배는 계산의 표시 간격만 바꾼다. 평범한 이동은 빨리, 일반 패스는 최대8배, 주요 크로스는 최대2배, 슛/선방/결과 접촉은 최대1배로 제한한다.

RAF 당 표시 시간 50ms/누적 계산 600ms 및 계산 예산6ms를 제한해 프레임 지연 후 슛을 건너뛰지 않는다. 앱 첫 메뉴, 숨긴 탭, 관리 화면, 전술/교체/대화의 일시 정지, 킥오프/하프타임/득점 안내 뒤에서는 계산 시간이 멈춘다. 돌아올 때 밀린 시간을 몰아서 진행하지 않는다. 양 팀 모든 현재 출전 이름과 전경 공은 실시간/다시 보기/동작 줄이기에서도 유지한다.

점유율은 소유/패스 비행 틱의 비율(데드볼 제외), 패스/성공/슈팅/유효슈팅/코너/프리킥/오프사이드/태클/반칙/선방은 실제 사건 누적이다. 선수 출전 시간은 playedTicks로 기록하며, 기존 분 표시에는 부분 출전을 올림한다. 상대 체력도 개인별 실제 이동 소모를 읽는다. 연습 두 상황 역시 정상 전개를 시뮬레이션해 75분 한 골 열세/80분 한 골 우세에 도착한다. 준비 로딩을 먼저 그린 후 독립 세계를 열며 본 시즌 상태는 멈춘다.

아주 짧은568×320 가로에서는 경기장과 통계/중계를 나란히 배치한다. 회전/숨김으로 캔버스 높이가0인 프레임은 그리지 않고 다음 유효 크기에 복구한다.

## 저장과 다시 보기

시즌/match schema10, 키 win-again-season-v17, 앱/패키지 ID는 그대로다. 기존 v10 진행/확정 경기와 released spatialSetup.version1 계산기를 보존한다. 이미 공개한 continuous version1 세계·로그·확정 영수증의 계산도 보존한다. version2는 프리킥 오프사이드와 가까운 간접 프리킥 골키퍼 예외를 수정한다. 새 규칙은 새 킥오프에만 적용하며 저장을 불러온다고 시즌을 넘기지 않는다.

준비 상태 전체, 상대 선발/배치/전술, 물리 RNG, 현재 세계와 틱 단위 지시 journal을 저장한다. 복원은 준비 상태에서 동일 명령을 동일 틱에 재생하고 세계/좌표/체력/로그/점수/구간 전체를 비교한다. 변조된 위치·RNG·체력·사건을 거부한다. 컵/유럽 fixture의 기존 분당8draw RNG 계약은 완전히 지난 분에만 진행하고, 축구 물리는 별도 RNG를 사용한다. 현재 시즌의 상대 선발도 다시 검증한다. 이 검증은 화면 모듈 초기화 전에도 동작하도록 능력 계산을 코어에 둔다. 실제 앱 재실행 회귀에서 준비 화면으로 잘못 돌아가던 문제를 수정했다.

완료 영수증에는 실제 틱, 출전 틱, 구간 경계, 사건/카드 틱, 양쪽 자책골 및 측정 통계를 기록한다. 합법 출전·교체·퇴장·득점·통계 관계를 검증한다. 확정 선수/재정/컵/유럽 기록과 다시 정산 방지는 기존 시즌 흐름을 따른다. 복원 캐시는 정확한 저장 시그니처4개로 제한한다. 다시 보기의 준비/명령/시작·끝 틱이 같은 좌표 클립도4개만 캐시하며, 반환 복사본을 바꿔도 캐시 원본은 유지한다.

다시 보기는 당시 준비 상태와 지시를 재생해 실제 슛 전55틱부터 결과 뒤25틱의 좌표만 가져온다. 현재 전술/최종 퇴장 명단을 과거 장면에 덮지 않는다. 계산 전에 준비 문구를 먼저 표시하고 조작을 잠시 잠근다. 장면 선택이 바뀌거나 닫히면 이전 준비 결과를 무시한다. 실제 기록 프레임 사이 보간만 사용하고 결과 문구는 사건 틱 전에 보이지 않는다. 읽기/이동/닫기는 본 경기 시간을 바꾸지 않는다.

## 검증과 한계

코드 커밋39de3ad의 전체157 suites/1177 checks가 로컬과 [GitHub 소스 검사](https://github.com/jaeseok614/win-again-football/actions/runs/38194336158)에서 통과했다. 공개 PWA14/Android 오프라인11그룹, Android14/15 [실제 네이티브9/9·빌드·lint](https://github.com/jaeseok614/win-again-football/actions/runs/38194336101)도 각각 통과했다. 최종 정확한 소스/브라우저/PWA/Android 결과는 HANDOFF.md 첫 항목과 PR25 해당 커밋 CI에 기록한다. 새 회귀는 100ms 이동/속도 독립/접촉/오프사이드/골 프레임/부분 저장/동일 분 지시/하프타임 교체/완료 영수증/실제 다시 보기/12포메이션/연습/리그·컵·유럽 연결을 검사한다. 이전8개 완료 v10 공간 저장의 정확한 복원과 정산을 별도로 비교했다. 브라우저 전체96분 경기의 표시 scheduler 결과가 직접 엔진의 모든 세계·로그·좌표·체력·RNG와 일치했다. 가속한 표시 시계를 사용한 조작 검사이며 96분 벽시계 관전이라고 주장하지 않는다.

전체 연속 세계는 구현했지만 FM 수준의 전술 AI/3D 신체 충돌 정확도를 주장하지 않는다. 움직임과 공중 궤적은 간략한 모델이고, 팀/역할 목표는 휴리스틱이다. 접촉 이후 반칙/카드 및 킥 오차/골키퍼 잡기는 능력과 물리 상황에 따른 결정적 난수를 사용한다. VAR, 정교한 파울 어드밴티지, 실제 부상 접촉 모델과 모든 IFAB 예외/경기 중단 판정은 없다. 팀당 퇴장은 최대4명으로 제한해 현재 게임을 끝낼 수 있게 한다. 오프라인/저사양 실기기 체감과 득점/슈팅 밸런스는 추가 플레이 표본으로 계속 조정할 범위이며, 공개된 version1 저장의 계산은 변경하지 않는다.
