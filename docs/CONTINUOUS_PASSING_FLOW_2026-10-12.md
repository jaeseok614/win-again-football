# 연속 경기 version5: 패스 연결·세컨드볼·상대 대응

2026-10-12. 새 확인 킥오프와 새 전술 연습에 적용합니다. 시즌/match schema10, 저장 키와 앱 ID는 유지합니다. 공개된 continuous1/2/3/4와 spatial1의 계산은 보존하며 진행 중인 경기와 확정 기록을 바꾸거나 시즌을 자동 전환하지 않습니다.

## 실제 움직임과 판단

- 패스 도착 예측에 100ms 공 감속·중력·착지 바운드를 사용합니다. 양 팀은 같은 최대3.2초 경로를 읽고 현재 속도·가속·체력으로 도달 가능한 지점을 비교합니다. 높은 공은 실제 받을 수 있는 높이까지 기다립니다. 미래 접촉/골대 반사/선수 충돌은 예측에 미리 확정하지 않으며 실제 엔진 접촉이 결과를 결정합니다.
- 일반 패스의 속도 외삽을 최대0.75초/3m, 크로스는1초/5m로 제한합니다. 갑자기 방향을 바꾸는 수신자에게 먼 외삽 위치로 공을 보내던 흐름을 줄입니다. 패스 오차는 기존 실제 능력과 RNG를 사용합니다.
- 소유자, 새 배달, 실제 마지막 접촉이 바뀌면 팀 계획을 즉시 갱신합니다. 원래 수신자가 가장 빨리 도달하는 동료보다0.4초 넘게 늦으면 동료가 경합합니다. 튕긴 공도 양 팀의 실제 도착 시간으로 경합하고 뒤의 커버를 유지합니다.
- 실제 첫 터치 뒤0.6초만 공을 정리하며 이후 정상 전진합니다. 다음 결정까지9~13틱의 능력 기반 시간을 둡니다. 일반 드리블을 결정 대기 전체 동안 정지하지 않습니다. 실제 수신 시점도 저장 재생 비교에 포함하며 변경을 거부합니다. 교체 선수의 수신 시점은 새로 초기화합니다.
- 중원은 세 개의 대각선 지원 위치 중 거리·수비 여유·패스 경로가 나은 곳으로 이동합니다. 방금 패스한 필드 공격/중원 선수는 짧은 대각선 반환 지원을 합니다. 뒤의 수비 커버, 오프사이드 선과 측면 크로스 지시의 폭은 유지합니다. 진영 교환에 대칭입니다.
- 경로 위험이 큰 일반 패스를 낮게 평가합니다. 크로스/슛 선택은 실제 주자·압박·골키퍼·접촉 규칙으로 이어지며 득점/슈팅 상한이나 성공률 보정으로 결과를 만들지 않습니다.
- 균형 운영 상대 감독은25분 이후 우리 전방 압박을 보면 체력이 가능한 경우 역습으로 대응합니다.20분 이후 실제 우리 패스40회 이상/성공률68% 초과, 충분한 자기 체력에서 압박을 비교합니다. 기존 늦은 열세/리드 대응과 저체력 우선 판단은 유지합니다. 상대 보고서는 현재 실제 지시를 표시합니다.

## 성능과 사용자 흐름

예측 경로는 세계/공 상태별 WeakMap에서 한 번 계산해 양 팀이 공유합니다. 팀 목표는 최대20명/5틱 캐시를 유지하며 소유/배달/지시/인원 변화에서만 즉시 갱신합니다. 숨김 UI에서 추가 보고서 계산을 하지 않으며 기존 준비·연습·리플레이 로딩을 유지합니다. 공, 양 팀 전체 이름, 중계, 배속/교체/지시는 기존 한 화면 구성을 사용합니다. 새 연습 씨드42/2는 정상 전개로75분0:1/80분1:0이 됩니다. 공개1~4 연습 씨드는 유지합니다.

## 참고와 남은 범위

HELIOS 공개 [기본 이동 판단](https://raw.githubusercontent.com/helios-base/helios-base/master/src/player/bhv_basic_move.cpp)은 자신/동료/상대의 예상 공 도착 시간을 비교해 경합하거나 원래 위치로 이동합니다. 이 개념을 참고해 우리 JS에서 가속·공 경로·수신 연결을 직접 구현했습니다. 외부 엔진 코드를 복사하거나 의존성을 추가하지 않았습니다. [RoboCup 서버의 물리 설명](https://rcsoccersim.readthedocs.io/en/latest/soccerserver.html)도 고정 간격 예측/실제 판정 분리의 참고 자료입니다.

역할 휴리스틱과2.5D 공중 모델입니다. 모든 판정 예외·의도적인 핸드볼·어드밴티지·3D 신체/VAR는 아직 구현 범위 밖입니다. 패스 빈도·슈팅 분포·로우 블록 공격 전개와 다양한 전력차/리그 표본은 계속 조정할 부분입니다. 공개 규칙5 이후 결과를 바꿀 때도 별도 규칙을 만들고 공개5 기록의 정확한 재생을 보존해야 합니다.
