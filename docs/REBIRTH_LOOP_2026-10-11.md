# 환생 도전: 끝이 있는 감독 생활

2026-10-11 사용자의 새 방향은 기능을 끝없이 늘리기보다, 실패와 재도전이 있는 축구 감독 게임입니다. 이번 변경은 실제 리그 결과 → 압박 → 단기 약속 → 최후통첩 → 경질 또는 생존 → 기억을 선택한 새 삶을 연결합니다. 경기 승패를 임의로 바꾸거나 유료 결제를 유도하도록 결과를 조작하지 않습니다.

## 참고한 공식 자료와 적용

- [Supergiant Games — Hades FAQ](https://www.supergiantgames.com/blog/hades-faq/): 반복 도전 사이의 영구 성장과 난이도 선택, 인물과 이야기가 이어지는 구조를 참고했습니다. 이 게임에서는 세 가지 기억 중 하나와 최근 12회차 요약만 이어집니다. Hades의 자산·문구·수치를 복제하지 않았습니다.
- [Football Manager — Supporter Confidence](https://www.footballmanager.com/features/supporter-confidence): 구단주와 팬의 서로 다른 기대를 참고했습니다. 이 게임에서는 구단주(승점), 팬(득점 또는 실점), 코치(승리 횟수)가 단기 요구를 제시합니다. 실제 FM의 경질 공식을 재현한 것은 아닙니다.

## 플레이 규칙

새 앱 구단은 환생 도전을 기본 적용합니다. 이미 진행 중인 유효한 v10 구단에는 소급 적용하지 않습니다. 홈의 **환생 도전 시작**에서 명시적으로 참여하면 현재 선수·자금·일정을 보존하고 그 이후 결과부터 계산합니다. 진행 중인 경기에서는 참여할 수 없습니다. 기존 시즌/엔진 버전과 저장 키는 그대로입니다.

- 이사회 여유 60으로 출발합니다. 리그 승리 +4, 무승부 −3, 패배 −8, 범위 0–100입니다.
- 여유 20 이하에서 다음 리그 3경기의 승점 3점이 필요한 최후통첩이 시작됩니다. 경고를 만든 경기 자체는 세 경기에 포함하지 않습니다. 달성하면 최소 28로 회복하며, 실패하면 그 삶은 경질로 끝납니다.
- 리그 6경기마다 면담을 제안합니다. 최후통첩이나 수행 중인 약속이 있으면 해당 시점의 면담은 생략합니다. 답하지 않은 면담이 있으면 다음 경기를 시작/확정할 수 없습니다.
- 구단주: 다음 3경기 승점 4 또는 6. 팬: 총 실점 3 이하 또는 득점 6 이상. 코치: 2승 또는 3승. 첫 선택지는 달성 +6/실패 −14, 두 번째는 달성 +14/실패 −24입니다. 경기 결과를 확정한 뒤에만 판정합니다.
- 컵·유럽 경기와 미확정 경기에는 압박 변화가 없습니다. 같은 시즌의 마지막 약속은 다음 시즌으로 이어질 수 있습니다.
- 1부 승격을 확정하고 그 시즌의 남은 대회까지 마치면 귀환 엔딩입니다. 환생 도전의 목표는 1부 귀환입니다. 적용하지 않은 기존 캠페인은 기존 장기 플레이를 유지합니다.

## 새 삶과 유예

경질 또는 귀환 뒤 **새 삶 준비 → 기억 선택 → 기억을 품고 환생**으로 진행합니다. 토투넘 원래 18명, 5부 첫 경기, 초기 자금으로 돌아갑니다. 이전 선수 성장·영입·자금은 복사하지 않습니다. 지난 삶의 요약과 리그 결과, 선택 기록은 최근 12회까지 보관합니다. 회차 숫자는 계속 증가합니다.

| 기억 | 다음 삶에서의 효과 |
| --- | --- |
| 평정심 | 시작 여유 +8 |
| 승부의 기억 | 리그 승리 회복 +1 |
| 버티는 법 | 무승부 여유 감소 없음 |

두 번째 삶부터 **기억으로 마지막 유예**를 회차당 한 번 쓸 수 있습니다. 기존 패배를 지우거나 경기를 다시 뽑지 않고 여유 35로 돌아옵니다. 같은 삶에서 두 번 쓸 수 없습니다. 현재 환생과 유예는 모두 무료입니다.

새 삶은 기존 저장 불러오기 트랜잭션으로 교체합니다. 교체 직전 전체 구단을 복구 백업에 보관하고, 저장 실패 시 기존 구단을 유지하며 재시도를 제공합니다. 사용자가 결말을 보기만 하거나 창을 닫아도 새 삶을 시작하지 않습니다. 새 회차 도입부는 선택한 기억과 반복된 감독실을 언급합니다.

## 과금 방향의 경계

실제 결제·가격·유료 재화·상점은 이번에 추가하지 않았습니다. 현재 유예는 반복 플레이와 종료 정책을 확인하기 위한 무료 기능입니다. 이후 계속하기 상품을 검토한다면 한 회차의 정해진 횟수만 허용하고, 무료 환생은 항상 남기는 방향입니다. 결과를 되돌리는 무제한 재추첨과 돈으로 경질 기준을 몰래 바꾸는 설계는 포함하지 않습니다.

실제 판매에는 플랫폼 영수증 검증, 서버의 구매 권한/소비 기록, 환불·복원 및 중복 요청 처리가 별도로 필요합니다. 현재 오프라인 JSON과 이전 삶 요약은 구매 권한 증명이 아니며 사용자 편집에 대한 보안 경계도 아닙니다. 유료 권한을 로컬 저장값만으로 구현하면 안 됩니다.

## 검증과 밸런스의 한계

초기 수치(승리 +5, 무승부 −2와 쉬운 약속)에서는 기본 선발을 자동 운영한 10개 seed가 최대 320경기 동안 거의 경질되지 않았습니다. 승리 회복을 줄이고 단기 약속을 조정했습니다. 최종 수치로 seed 1–10, 기본 선수단, 추가 훈련/영입/전술 조정 없이 첫 번째 약속을 고르는 실험에서는 8회가 1부 귀환, 2회가 2부에서 경질되었습니다. 귀환은 4–5시즌, 경질은 4/6시즌이었습니다. 이것은 작은 결정론적 시뮬레이션이며 실제 사용자의 체감 난이도를 증명하지 않습니다. 피로 관리, 실제 교체, 훈련, 전술, 면담 선택을 하는 사용자 데이터로 추가 조정해야 합니다.

순수 모델 검사는 실제 약한 선수단의 경기/경질, 3경기 유예, 목표 판정, 시즌 경계, 실제 1부 귀환, 환생 초기화, 저장 복원, 중복 선택 거부, 컵 제외를 다룹니다. UI 검사는 숨겨진 경기 화면의 추가 계산 방지, 팝업 읽기의 무변경, 두 단계 환생, 저장 실패 복구, 중복 클릭, 결말 후 관리 행동 차단과 연습 분리를 다룹니다. 최종 전체 검사 수와 산출물 해시는 HANDOFF.md를 확인하세요.

화면은 홈의 기존 버튼 공간과 한 개의 팝업을 사용합니다. 경질/환생 확인/규칙 두 페이지/회귀 기록을 320×568, 390×844, 844×390에서 검사해 본문 스크롤 0, 문서 넘침 0, 모든 버튼 44px 이상을 확인했습니다. 실제 브라우저에서 경질 우선 표시, 무료 유예의 결과/자금/경기 보존, 6경기 면담 선택, 새 삶의 원래 선수단과 기억 도입부를 확인했습니다. QA 구단과 화면은 저장소 밖에 보관합니다.
