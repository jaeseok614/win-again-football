# 공 받기와 달리기 연결 개선

사용자의 ‘게임 움직임을 더 유연하게’ 요청을 반영했다. 표시 전용 변경으로 엔진의
경기 시간, 선수 능력, RNG, 사건/득점 기록과 저장 스키마는 바꾸지 않는다.

- 일반 패스는 기존 768ms 비행 시간을 유지하되 완만한 가속/감속과 작은 곡선을
  사용한다. 공과 잔상은 동일 경로를 따른다. 슈팅은 기존 1,400ms를 유지한다.
- 받는 선수는 공 쪽으로 최대 2.4 피치 단위 움직이고, 동료 중원/공격수는 측면과
  앞 공간을 벌린다. 구간 양 끝에서 오프셋과 기울기가 0으로 돌아와 다음 패스나
  경합으로 넘어갈 때 점프하지 않는다. 기존 탈취 접촉/회수 순서를 유지한다.
- 크로스·컷백·침투 패스·패스 연계를 받은 뒤 500ms 동안 작은 첫 터치로 골문 쪽
  슈팅 위치를 만든다. 공은 선수 발과 같이 이동한다. 코너 헤더·직접 프리킥·
  개인 돌파의 기존 경로는 유지한다. 실제 중계와 리플레이는 같은 계산을 쓴다.
- 양 팀 발동작은 화면상 실제 이동량에 맞춘다. 정지하면 잦아들며 방향 전환 시
  몸 기울기를 완만하게 바꾼다. 우리 선수 이름은 기울이지 않고 유니폼에만 적용한다.
  프레임 간 자세는 표시 상태에만 남고, 새 선수/정적인 화면은 중립 자세로 시작한다.
- 일시 정지/숨김에서는 자세와 시각 시간이 고정된다. 선택 배속과 결정적 장면의
  속도 상한, 결과를 공 도착 후 공개하는 기존 규칙을 유지한다.

## 검증

전체 **129 suites / 959 checks** 통과. 새 5그룹은 패스 도착 감속/정확한 발 위치,
양 팀 네 가지 전개 뒤 첫 터치, 실제 이동/정지에 따른 발동작, 방향 전환/일시 정지/
교체 선수 자세, 원본 프레임과 구단 상태 불변을 검사한다. 기존 12포메이션/양 팀
공격 경로·장면 경계·위치 상한·실제 골키퍼 접촉·저장/RNG 검사도 통과했다.
기존 발동작 테스트는 마지막 진행 프레임을 기준으로 정지 보존을 검사하도록 조정했다.
80ms 단위로 같은 발동작을 쓰던 캐시 대신 변한 값만 0.1 단위로 DOM에 쓴다.

이동 스냅샷 동일, 브라우저 콘솔 오류 없음 확인. 320×568/390×844/614×672/844×390
모두 문서의 가로/세로 넘침 0, 경기장과 하단 조작이 화면 안에 있었다.
