# 선택을 기억하는 감독 대화

FM24의 [개인 목표와 대화 로직 공식 설명](https://www.footballmanager.com/features/individual-player-targets-and-interaction-logic)은 상황·성격·관계를 고려한 반응, 반응의 이유 설명, 구체적인 약속 진행을 강조한다. 이 원칙을 기존 토투넘 서사에 적용했다. 새 훈련·계약 시스템을 암시하지 않고 실제 게임에서 확인할 수 있는 배치, 체력, 주급, 출전 계획으로 대화를 연결한다.

WEBTOON의 [Back to First Base 공식 소개](https://us.webtoons.com/en/sports/back-to-first-base/list?title_no=10883)에서 확인한 후회, 두 번째 기회, 관계 회복이라는 구성을 참고했다. 에피소드 대사를 재현하거나 열람했다고 주장하지 않는다. 이번 감독의 속말, 인물, 장면과 모든 대사는 토투넘 게임용으로 새로 작성했다.

## 바뀐 흐름

- 취임 도입: 낯선 계약서에 적힌 자기 이름 → 추락한 구단의 일정표 → 책임을 요구하는 구단주. 짧은 속말과 직접 대사를 번갈아 보여준다.
- 구단주·수석 코치·주장·팬의 첫 면담을 다시 썼다. 첫 대답 세 가지마다 서로 다른 후속 질문과 두 결말을 제공해 총 12개 후속 대화/24개 결말이 이어진다.
- 구단주는 낙관을 곧바로 칭찬하지 않고 첫 패배와 재정 압박을 묻는다. 코치는 지원 위치·압박 뒤 커버·역습 연결을, 주장은 말할 권리·경쟁 기준·책임을, 팬은 기다림과 설명을 묻는다.
- 이 네 장면에는 맥락과 관계없는 공통 충성도 문장을 덧붙이지 않는다. 실제 성격별 경기 집중 반응은 기존 StoryMood가 계산한다.
- 한 장면/질문/반응씩 기존 이전·다음으로 읽는다. 선택 전에는 결과를 보여주지 않는다. 대화 후 전술·선수단 화면에서 직접 결정한다.

## 데이터와 효과

기존 `clubStory.version=1`, `listen/bold/practical`, `commit/honest`, 배우 identity와 시점 영수증을 그대로 사용한다. 대사로 돈, 능력치, 전술, 통계 또는 출전 약속을 새로 만들지 않는다. 최종 답변의 기존 관계/일시적 집중 효과만 적용한다. 유망주의 실제 두 리그 경기 30분 약속, 갈등·지역·시즌별 특수 후속 질문은 유지한다. 읽기, 과거 대화 재생, 파일 복원은 효과를 다시 적용하지 않는다.

기존 완료 기록도 선택 ID에 대응하는 다듬어진 문장으로 재생된다. 원문 대사의 스냅샷을 저장하는 변경은 없다.

## 검증 범위

`test-story-dialogue.cjs`는 실제 3경기 확정 상태에서 12개 분기 × 두 결말, 파일 내보내기/복원, 중간 영수증 호환, 중복 적용 거부, 선택 전 숨김, 재생 일관성, 경기·재정·통계 불변 및 유망주 약속을 검증한다. 기존 구단 이야기 테스트의 옛 문구 일치 두 검사를 현재 분기/승격 기준 검사로 바꿨다.

브라우저에서 새 취임, 승격/재정 선택의 서로 다른 후속 질문, 선택 뒤 집중도 반응을 확인했다. 취임 두 번째 장면의 경질 설명을 포함해 320×568, 390×844, 844×390, 1280×720에서 본문/대화상자의 스크롤 높이와 표시 높이가 동일하다. 최종 회귀/배포 결과는 HANDOFF.md에 기록한다.

PWA 대사 증가에 맞춰 shell 상한을 3,885,000에서 3,890,000바이트로 5KB만 늘렸다. 최종 shell은 3,886,338바이트(+6,481), 이미지와 초상화 atlas 개수/크기 제한은 그대로다.
