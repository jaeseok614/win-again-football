# 가로 전용 감독 작업 공간

사용자 최신 요구는 가로 전용입니다. AGENTS.md에 영구 기준으로 기록했습니다.
Android sensorLandscape, 설치형 웹 앱 landscape 요청, 일반 브라우저 세로 회전 안내와 일시 정지를 사용합니다. 회전만으로 경기를 재개하지 않습니다.

- 네이티브 드롭다운 대신 11개 경기 메뉴가 왼쪽에 표시됩니다.
- 전술 배치판, 위치별 종합/기본 평균, 포메이션/공격/수비 지시, 선택 선수의 능력·체력·컨디션을 같은 화면에 표시합니다. 역할/지원 관계는 배치판을 유지한 채 오른쪽 패널을 바꿉니다.
- 이동 중 위치별 예상 종합과 팀 평균을 미리 보여줍니다. 동료 자리에 놓으면 두 선수의 위치와 평가를 함께 갱신합니다. 취소는 저장하지 않습니다.
- 위치 평가는 기존 능력의 포지션별 가중치에 익숙하지 않은 자리 -4(같은 라인)/-12(다른 라인), 불리한 측면 주발 -2를 적용한 코치 예상입니다. LS/RS 등 세부 명칭은 ST 등 기준 능력표를 공유합니다. 기본 종합과의 차이는 영구 능력 상승이 아니며 물리 규칙1~9에 추가 보너스를 넣지 않습니다.
- 작은 전술 마커는 성/짧은 이름을 사용하며 접근성 이름과 선택 선수 패널에 전체 신원을 유지합니다. 실시간 경기의 양 팀 전체 이름 지침은 유지합니다.
- 코치 선발은 경기 전 비교/검토/명시적 적용 흐름을 유지합니다. 팀 대화 이후나 경기 중에는 실제 출전 명단·체력·배치 평가를 보여주고 전체 선발 변경은 잠급니다.
- 구단 신원에 고정된 원본 SVG 엠블렘을 기존 구단 마크와 순위/컵 대진표에 적용합니다. 외부 다운로드나 실제 구단 로고 복제 없이 오프라인 표시합니다.
- 가로 홈 화면에서도 구단 성장 그림을 유지합니다. 선수/코치 이미지는 기존 공유 아틀라스를 재사용합니다.

검증: Chrome 568×320,640×360,740×360,844×390,915×412,1024×768,1280×720에서 12개 포메이션의 배치판/능력 패널 경계, 실제 드래그/역할 변경, 코치11명/적용 버튼, 컵7대진/실제8구단 엠블렘, 진행 경기 일시 정지와 회전 안내를 확인했습니다. 가로320px 높이에서는 조밀한 배치/코치 행의 터치 영역을 줄이고 기본 메뉴·닫기·실제 적용은44px 이상으로 유지합니다. 세부 선수 설명은 패널 안에서 스크롤할 수 있습니다.
전체 회귀 테스트 및 Android 기기 테스트 결과는 HANDOFF 최신 항목에 기록합니다.
