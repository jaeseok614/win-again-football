# 전술 지원 지도와 작전 브리핑

EA FC 25 Gameplay Refresh의 공격 지원 움직임과 FIFA Manager 12 매뉴얼 17쪽의 Stats Centre·Assistant Manager's Advice를 참고했습니다.

- https://eaassets-a.akamaihd.net/eahelp/manuals/FIFAM12pc.pdf

## 구현 범위

전술 팝업의 정지 배치에서 필드 동료를 28 좌표 단위 거리로 찾습니다. 각 선수의 가까운 두 동료 연결을 중복 없이 그리고 선택 선수 연결을 강조합니다. 선택 선수는 가까운 동료 전체 수와 앞쪽(y가 3 이상 낮음) 동료 수, 가까운 세 동료의 이름·거리를 읽습니다. 골키퍼와 현재 우리 퇴장 선수는 연결에서 제외합니다. 폭·깊이, 지원 없는 선수와 8 미만 거리의 겹친 배치를 표시합니다. 드래그 중에는 이전 연결을 숨기고 완료·취소 때 다시 계산합니다. 연결 토글은 화면 설정이며 캠페인을 저장하거나 진행하지 않습니다.

이 지도는 배치 거리이며 실제 패스 횟수·성공률·상대 수비 차단 분석이 아닙니다. 좌표 변경은 표시 출발 위치를 바꿉니다. 엔진 능력치 보너스나 새로운 AI 달리기 규칙은 추가하지 않았습니다. 사용자는 기존 역할·전술·포메이션 효과를 별도 전술 분석에서 확인합니다.

브리핑은 현재 시각 이전 최근 15분의 실제 로그만 읽습니다. 시작 경계는 제외하고 현재 시각을 포함하며 득점은 슈팅에도 포함합니다. 우리:상대 순서와 교체 여유를 명시합니다. 현재 퇴장, 체력 55 미만, 상대 슈팅 우세, 65분 이후 열세, 배치 고립/겹침, 실제 활성 출전 약속 순서로 최대 네 조언을 표시합니다. 교체를 모두 소진하면 전술 분석으로 안내합니다. 약속은 확정 리그 기록만 집계합니다. 버튼은 기존 팝업을 열며 교체·지시를 자동 실행하지 않습니다.

## 보존과 검증

새 저장 필드나 RNG 호출은 없습니다. 기존 save key와 복원 형식을 유지합니다. 전술 팝업에서만 모델을 읽고 숨겨진 패널의 경기 tick 계산을 늘리지 않습니다. 기존 팝업의 중지·Escape·포커스 규칙을 재사용합니다. 펼친 브리핑은 선수 재배치/지도 토글 중 유지합니다. 라이브 화면과 두 행 버튼 구조를 유지합니다.

`test-touchline-plan.cjs`는 12개 포메이션, 순수성, 거리·앞쪽 동료·연결 중복, 고립과 겹침, 최근 이벤트 경계, 실제 우리 퇴장, 교체 소진, 출전 약속, 불완전 입력을 검사합니다. `test-tactical-editor.cjs`는 토글의 저장 불변성과 배치 후 선택 연결 갱신도 검사합니다. 브라우저 검증은 작은 세로 화면, 가로 화면, 데스크톱과 실제 전반 종료 기록을 사용합니다.

이번 변경의 로컬 검증: 94개 테스트 묶음 / 827개 검사, 생성한 PWA 14개 검사 통과. 라이브 페이지 360×640·844×390·1280×800에서 페이지 스크롤 없이 정확히 두 행 버튼을 확인했습니다. 새 캐시의 최종 빌드에서 선택 연결·브리핑 펼침 유지·체크박스 동작을 확인했습니다. 빌드 CSS 공백/주석을 축소해 공개 번들의 기존 4.5 MB 제한을 유지합니다. 문자열·이스케이프·calc 간격 보존과 다른 OS 복제 빌드도 검사합니다.

## 선수 카드와 연결 궁합 추가 (2026-10-05)

전술 배치 카드에서 선발 선수 11명의 이름을 줄바꿈으로 모두 보이게 하고 종합·현재 체력을 표시합니다. 전술판 위에는 활동 중인 선발의 평균 종합·체력을 보여줍니다. 종합은 등록 주 포지션의 주 능력 55%, 패스·속도·지구력 각 15%이며 현재 체력과 구분됩니다.

연결선의 숫자·색은 두 선수의 패스(30%), 정해진 팀워크 성향(30%), 현재 선택한 역할 적합도(25%), 더 낮은 체력(15%)에서 계산한 코치 분석 점수 0–100입니다. 80 이상은 잘 맞음, 65 이상은 무난함, 그 아래는 조율 필요로 표기합니다. 선수를 선택하면 이름과 네 구성 점수, 거리까지 읽을 수 있습니다. 전술판의 숫자는 실제 패스 확률이나 공동 출전 기록이 아니며 경기 엔진의 보너스를 새로 만들지 않습니다. 구형 저장을 위한 새 필드는 필요하지 않습니다.

360px 폭에서 5-3-2, 4-1-2-1-2, 4-4-2, 3-4-3, 4-2-3-1의 11명 전체 이름이 잘리지 않고 카드가 겹치지 않음을 브라우저에서 확인했습니다. 모델은 12개 포메이션과 읽기 순수성, 궁합의 대칭·범위, 역할·체력 반응을 검사합니다. 새 정보량을 포함한 PWA 크기는 4,503,247바이트이고 4.55MB 미만 제한으로 검사합니다.
