# 토투넘 시작과 선수 성격 — 2026-10-05

새 게임은 현실과 다른 가상 세계에서 강등된 토투넘 핫스퍼를 맡습니다.
이름의 참고 명단은 [토트넘 공식 2024/25 등록 선수 안내](https://www.tottenhamhotspur.com/news/986873/202425-premier-league-squad-numbers-confirmed)입니다. 손헝민, 솔랑케잉, 매디쏜, 쿨루셉스키, 로메로우 등 패러디 18명을 사용합니다. 최신 실제 명단이나 실제 능력/성격을 재현한다고 주장하지 않습니다.

새 프로필은 별도 `sp_*` identity로 등록합니다. 옛 기본 선수, 시장·유소년 identity는 그대로입니다. 원래 `brynwell` 구단 ID, 원시 이름과 영문 순위 키는 유지하며 표시 이름만 토투넘으로 바꿉니다. 중복 방지를 위해 기존 토튼햄 상대의 표시 이름은 블랙본으로 옮깁니다.

UI의 새 구단 생성은 `Season.create(...,{startingClub:true})`를 사용합니다.
저장에는 `startingClub:'tottunham'`을 남겨 초기 재정 계약과 통계 계약을 검증합니다. 구단 ID나 저장 키를 바꾸지 않습니다. 기존 모델 호출은 기본 명단을 사용해 옛 캠페인과 격리된 회귀 fixture를 유지합니다.

선수 상세의 기술 8 / 정신·성격 6 / 신체 6 항목은 1–20 척도입니다.
기술·신체는 훈련되는 기본 경기 능력의 조합으로 산출됩니다. 정신·성격은 identity별로 고정되며 경기 RNG를 소비하지 않습니다. 높은 충성도는 격려, 프로 의식과 승부욕은 분발 요구, 낮은 압박 대처는 침착하라는 말의 효과를 조절합니다. 자신감의 ±3 제한과 최대 3% 경기력 영향은 유지합니다. 팀워크·리더십은 현재 선수 보고서의 성격 정보이며 별도의 새 경기 효과는 없습니다.

신규 대화 결정의 `rules:2`는 새 반응 공식을 지정합니다. 과거 결정의 규칙 필드 부재는 공식 1을 뜻하며 원래 반응과 구간 지표를 다시 계산합니다. 규칙 변조와 반응 변조는 거부합니다.

실시간 중계는 관전 전용이며 선수 클릭/드래그가 모두 차단됩니다.
선수 배치는 전술 팝업에서만 조정하며 기존 customPositions 저장/가져오기 검증을 재사용합니다. 세부 배치는 기존처럼 2D 기본 위치에 반영되고 시뮬레이션 판정이나 RNG에 새 효과를 추가하지 않습니다. 교체 팝업에는 선발 전체가 있습니다.

스토리와 조작 가이드는 별도 기기 설정 `win-again-manager-guide-v1`으로 완료를 기억합니다. 기존 구단을 불러올 때 자동으로 나타나지 않습니다. 첫 가이드에는 실제 선수 보고서와 전술 창을 열어 닫아보기, 팀 대화 선택 후 실제 반응 확인하기가 포함됩니다. 가이드만으로 킥오프하지 않습니다. 새 이야기 준비 버튼은 구단 가져오기 미리보기만 만들고, 적용 전에는 현재 저장을 바꾸지 않습니다. 적용 후에는 기존 가져오기 백업으로 되돌릴 수 있습니다.
