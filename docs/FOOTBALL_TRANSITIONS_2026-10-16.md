## 실제 축구 동작에서 고친 부분

- 공과 가까워도 태클할 수 없는 뒤쪽 선수가, 앞쪽에서 공을 노리는 다른 수비수의 경합을 막던 선택 오류를 수정한다. 공의 실제 거리·접근 방향·태클 재시도 시간으로 판단하며 결과는 접촉 때 결정한다.
- 골키퍼는 공과 양 골대가 만드는 각도를 읽어 위치를 잡는다. 슈팅 뒤 반응 시간이 지나면 현재 골키퍼 깊이의 접촉점을 향한다. 골라인으로 먼저 물러나거나 세이브를 미리 확정하지 않는다.
- 전환은 실제 통제권을 되찾은 때부터 판단한다. 역습 공격수 한 명을 출구로 남기고, 체력과 위치를 만족하는 수비·중원은 골문 쪽으로 복귀한다. 달리는 공격수의 전방 패스는 실제 속도를 반영하고 리드 거리를 제한한다.
- 크로스는 실제 비행 시간에 맞춘 공중 궤적을 사용한다. 수신 선수는 예상 접촉점에서 자신의 가속도로 감속해 공보다 먼저 지나치지 않는다. 실제 공중 접촉 이후에만 헤더 슈팅이 발생한다.
- 측면 프리킥은 상황에 따라 박스로 올린다. 중앙의 직접 슈팅과 구별하며 명시적으로 지정한 키커를 유지한다. 지정이 없는 경우 실제 킥 관련 능력으로 선수를 선택한다.

## 가로 한 화면에서 읽고 확인하기

경기 기록의 ‘슈팅 위치’는 이번 경기에서 실제 위치와 완료 결과를 함께 기록한 장면만 표시한다. 우리/상대 필터, 선수 이름·얼굴, 분·거리·xG·박스 안/밖, 완료 결과를 같은 화면에서 읽는다. 양 팀의 공격 방향을 위로 맞추며 라이브 경기장과 구별한다. 원본 위치가 없는 득점이나 자책골의 위치를 만들어내지 않고 지도 등록 범위를 표시한다.

선택한 슈팅은 기존 리플레이 버튼에서 그 슈팅의 실제 계산 장면으로 바로 연결한다. 골대·선수 이름·공의 앞뒤 표시 순서와 당시 22명의 계산 좌표를 재사용한다. 복귀하면 같은 필터와 선택을 유지한다. 이 읽기와 재생은 시간·RNG·체력·재정·시즌 결과를 변경하지 않는다.

물리 슈팅은 공을 찼을 때 이미 시도 수에 포함된다. 공개 대기 중인 결과를 읽을 때는 그 이전 시도 수를 빼지 않고, 공개 전 골/세이브 결과만 숨긴다. 원래 시도가 없는 터치 득점은 기존 방식대로 공개 전 점수와 신규 시도를 숨긴다.
