# 누적 경고와 다음 경기 출전 정지

우리 구단만 적용하는 간단한 게임 규칙이다. 상대 구단의 카드는 해당 경기 안에서만 적용한다.
리그·국내컵·유럽 대회를 따로 집계한다. 확정된 경기의 경고 3회 또는 퇴장은 해당 대회 1경기 정지다.
퇴장한 경기의 경고는 누적에 중복 합산하지 않는다. 다른 대회에 참가해도 정지는 줄지 않는다.
새 시즌에는 경고와 미집행 정지를 초기화한다. 공식 축구 규정의 재현을 뜻하지 않는다.

18명 선수단에서 건강한 선수를 제외한 뒤 GK 1 / DEF 4 / MID 5 / FW 3명을 유지할 수
없으면 일부 정지를 다음 같은 대회로 연기한다. 모든 제공 포메이션을 계속 사용할 수 있다.
부상 중에는 경기에 쉬면서 정지도 집행된다. 선수 identity로 연결하므로 영입 대체 선수에게
정지가 넘어가지 않는다. 팀 대화 이후 출전 정지 재배정이 필요한 영입은 막는다.

새 앱 구단은 Season.create(seed,{suspensions:true})를 사용한다. 기존 저장과 기본 모델 생성은
원래 규칙을 유지한다. 기존 저장은 카드가 활성화된 경기 준비 0분, 팀 대화 전에 홈에서
적용할 수 있다. 적용 이전의 카드는 소급하지 않는다. save key와 RNG는 변경하지 않는다.
설정의 origin 이후 statistics의 cards와 suspended identity 목록에서 상태를 계산하며,
복원 때 규칙 표식, 선수 상태와 기록 일관성을 검증한다. 숨긴 홈에서는 패널을 계산하지 않는다.

검증: 누적/퇴장/대회 분리/인원 부족/영입/손상 저장, 실제 두 시즌의 매 경기 복원,
추천 및 교체 제외, 기존 저장 적용, UI 비활성 버튼과 이름 이스케이프를 자동 검사한다.
실제 브라우저에서는 별도 origin의 테스트 구단만 가져와 개인 구단을 보존한다.
