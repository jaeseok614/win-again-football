# 패러디 축구 세계관

실존 축구의 분위기는 알아볼 수 있지만 실제 구단·선수 이름을 그대로 복사하지 않는 표시 이름 계층입니다. 경기 규칙과 저장 데이터는 기존 v22와 호환됩니다.

구단 `id`, 영문 정렬 키 `en`, 능력치, 대진과 색상은 바꾸지 않습니다. `Season.club()`과 `Europe.club()`이 화면용 이름을 돌려주고, `Season.rawClub()`과 `Europe.rawClub()`은 저장·경기 검증용 원본을 돌려줍니다. 과거 중계 문자열은 `Season.displayText()`가 표시할 때만 번역합니다.

## 상대 선수와 요주의 선수

`Opposition.roster()`는 구단 ID와 포지션으로 고정된 패러디 이름을 선택합니다. 선수 identity인 `opposition:<club-id>:<index>`는 유지됩니다. 일반·구버전 대회의 원본 프로필은 그대로 두고, 새 5부 리그 경기에서는 해당 디비전의 보정 프로필을 선수단 생성에도 적용합니다.

각 구단에는 에이스 공격수, 플레이메이커, 수비 리더 또는 골문 장벽 한 명이 있습니다. 홈의 다음 경기 카드와 경기의 상대 보고서는 실제 예상 선발 11명 안에 있는 선수를 요주의 선수로 표시합니다. 상대 보고서는 읽기 전용이며 시즌 시간, RNG와 저장 JSON을 변경하지 않습니다.

## 호환 규칙

- 저장 키 `win-again-season-v17`과 시즌 스키마 버전을 유지합니다.
- 과거 저장 안의 `homeName`, `opponentName`, 경기 로그는 다시 쓰지 않습니다.
- 구단 ID와 상대 선수 identity를 이름으로 대체하지 않습니다.
- 순위 동률 정렬은 기존 `en` 값을 계속 사용합니다.
- 새 표시 이름을 저장 검증 조건으로 사용하지 않습니다.
- 토투넘 새 경기의 버전 6은 크로스·컷백·침투 패스 등 공격 전개를 저장합니다. 예전 버전 5 경기 저장은 기존 결과와 RNG를 유지합니다.
- 선수 사진이나 실제 구단 문장은 사용하지 않고 기존 창작 그래픽을 유지합니다.

관련 회귀 검증은 `source/test-football-world.cjs`, `source/test-opposition.cjs`, `source/test-live-integration.cjs`에서 담당합니다.
