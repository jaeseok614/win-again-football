# 가로 경기 통계와 관리 화면 수정

## 사용자 피드백

양 팀 선발 명단의 이름/능력치가 겹치고 선수단/영입 진입 화면은 한 화면에 들어오지 않았습니다. 전술 미리보기 선택이 교체 창으로 넘어가고, 골 연출 본문/버튼이 좁은 경기장에서 겹쳤습니다. 오른쪽은 큰 요약 타일 대신 실제 축구 통계 비교가 필요했습니다.

## 변경

- [사용자가 지정한 FotMob 아탈란타–베네치아 통계 화면](https://www.fotmob.com/ko/matches/venezia-vs-atalanta/284hmb#5749690:tab=stats)의 중앙 항목/좌우 수치, 점유율 막대, 비교 색상 배치를 참고했습니다. 사이트의 수치나 자료를 게임 기록으로 복사하지 않습니다.
- 경기 옆에 점유율과 12항목(기대 득점, 전체/유효 슈팅, 패스/성공률, 코너킥, 반칙, 성공 태클, 선방, 오프사이드, 경고/퇴장)을 표시합니다. visibleMatchForReports와 Matchday.facts의 실제 기록을 사용하고 패스 성공률은 성공/시도에서 계산합니다. 킥오프 전은 기록 대기/—, 기록이 없는 항목도 —입니다. 이전 비연속 경기의 점유율은 추정으로 표시합니다. 게임 내 xG이며 외부 실측 지표가 아닙니다.
- 경기장은 표시 비율 약1.6을 유지하며 오른쪽 최소 폭을 확보합니다. 물리 좌표/속도/전술 규칙은 변경하지 않습니다. 골 제목/득점자/설명/고정44px버튼은 같은 열 안에 놓고 공통 footer/scoreboard 여백을 명시적으로 초기화합니다.
- 하단 선수단 메뉴는 18명 명단/선택 선수 능력으로, 영입 메뉴는 필터/후보8명/현재 선수 비교/실제 비용으로 직접 열립니다. 관리 업무 드롭다운에서도 전체 선수단이 같은 화면으로 연결됩니다.
- 교체 창은 기본 선택 없이 선발11명과 후보7명을 동시에 보여 줍니다. 명시적으로 선수를 눌렀을 때만 그 신원을 전달합니다. 전술 내 중복 교체 메뉴는 숨기고 실제 경기 버튼을 유지합니다. 코치 추천은 짧은 안내로 남깁니다.
- 킥오프 양 팀22명 이름/포지션/종합 수치의 각 셀을 고정합니다. 공통 ceremony small 요소의 전체 열 점유가 이름 칸을 밀던 문제를 수정했습니다.
- 영입의 실제 비용/교환 선수/계약 확인 및 기존 대화·예산·주간 제한은 그대로 적용합니다. 필터만으로 조회되고 긴 검색 조건은 명시적으로 열 수 있습니다.

## 검증

source/browser/phone-workspaces.cjs는 실제 하단 메뉴 클릭, 작은 가로 화면 8크기, 명단/본문 내부 넘침,44px 교체 버튼, 동일 신원, 영입 견적/취소, 기록 표시 불변성을 검사합니다. 기존 FM 목록/선수 보고서/전술/안내 브라우저 회귀와 전체 소스 검사 및 Android API34/35 검사를 수행합니다. 최종 결과와 배포 파일은 HANDOFF 최신 항목에 기록합니다.

저장 형식/엔진/경제 규칙/시즌 진행은 변경하지 않았습니다. 실제 기기 글꼴과 화면 높이에 따라 최종 검증 캡처를 확인해야 합니다.
