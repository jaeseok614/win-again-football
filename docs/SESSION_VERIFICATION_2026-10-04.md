## 자동 검증

전체 `node source/run-tests.cjs`: 85개 파일 / 780개 검증.
공개 `PWA_DIST=. node source/test-pwa.cjs index.html`: 14개 검증.
`node source/build-android.cjs`: 오프라인 자산 생성 통과.
각 PR은 소스 검사와 Android APK/AAB/lint/에뮬레이터 검사 성공 뒤 병합합니다.

새 구단·구버전 구단 2시즌 연속 플레이 검증은 62경기와 행동 직후 1,052회
정확한 복원을 정규 CI에 포함합니다. 별도 5개 시드·4시즌 실험에서는
323경기 / 6,003회 행동 직후 복원이 일치했습니다. 테스트 구단은 개인 저장과 분리했습니다.

## 실제 브라우저 확인

360×640과 1280×900에서 새 UI를 직접 사용했습니다. 시즌 전환, 선발 계획 적용,
영입 취소/확정, 관심 목록 재접속, 통산 기록, 중첩 경기 기록, 리그 필터를 확인했습니다.
리그 테스트는 2:2 종료 시점의 미확정 점수와 확정 뒤 다른 3경기 결과·승점 1 반영을
구분했습니다. 모바일 대화상자 닫기 버튼 폭 문제를 발견해 수정했습니다.
선수단 탭은 좌우 화살표/Home/End로 이동하고 재생성된 탭과 필터에 초점을 유지합니다.
마지막 모바일 점검에서 기존 선수 상세 링크의 높이 38/42px를 44px로 맞췄습니다.
테스트 서버를 중지한 뒤에도 가져온 구단을 오프라인으로 다시 열고 리그·통산·영입 검토를 확인했습니다.

## 구단 파일 이동

실제 UI로 내보낸 2시즌 2라운드 테스트 파일(176,053바이트)을 서로 다른 로컬
브라우저 저장 공간의 공개 단일 HTML 빌드로 가져왔습니다. 공개 read-only 도구로
가져오기 전후 **전체 season JSON과 모든 캠페인 설정이 정확히 일치**함을 확인했습니다.
자금 £257,350, 선수 18명, 선발 계획 `리그 주전`, 관심 선수 1명, 과거 1시즌 기록을
포함합니다. 처음 방문한 환경에서도 가져온 직후 `내 구단 이어서 하기`가 표시됩니다.

이 검증은 같은 컴퓨터의 서로 다른 브라우저 저장 공간을 사용했습니다.
실제 회사 컴퓨터를 원격 제어하거나 자동 클라우드 저장 동기화를 구현한 것은 아닙니다.
코드는 GitHub `main`에서 이어가고, 개인 플레이 저장은 게임의 저장 파일로 옮깁니다.
테스트 JSON·브라우저 저장·개인 자료는 저장소에 커밋하지 않습니다.
