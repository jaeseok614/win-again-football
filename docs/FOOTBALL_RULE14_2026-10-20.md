## 움직임과 압박·역습

기존 일반 전술에서는 속도62 이하의 볼 운반 선수가 열린 공간에서도 질주하지 못했다. 역습의 탈취 구간에는 이 제한이 풀렸고, 다른 전술의 공격수는 문전 침투에도 대부분 조깅했다.14는 공간·가까운 상대·현재 체력·순간 체력을 함께 확인해 모든 전술의 운반 선수와 문전 공격수에게 질주를 허용한다. 실제 달리는 속도는 원래 선수 능력과 체력으로 계산한다. 역습은 탈취 뒤 더 이른 침투와 직접 패스의 특성을 유지한다.

태클 시도는 실제 접근 속도에 따라 순간 체력과 체력을 쓴다. 자리를 잡은 수비의 부담은 달려들며 뻗는 태클보다 작고, 지구력도 소모에 반영한다. 이 계수는 이 게임의 자체 단위다. 전술 이름에 따라 태클·슈팅 성공률이나 승률을 곱하지 않는다.

모든 수비를 더 깊게 내리거나, 추격 중인 수비수까지 감속하거나, 압박 직후 패스를 강제하는 후보도 비교했다. 대형별 편향 또는 공격 정체를 악화시켜 채택하지 않았다. 최종 조합은 shared-kinetic이며, 실험용13 태그를 붙인 복사본은 공개13의 엔진이나 공개14 검증 결과로 취급하지 않는다.

## 반응성과 저장

핵심 관전의 위치 요약에서는 보이지 않는 매 틱의22명 화면 복사본을 만들지 않는다. 실제 물리 틱은 모두 계산하고, 슈팅·카드·득점·중단 경계와 전체 관전의 연속 좌표는 유지한다. 같은 틱까지의 전체 경기와 기록이 정확히 같다는 검사를 추가했다.

14는 선수 충돌의 이동 경계값을 작은 Float64Array에 보관한다. 접촉으로 움직인 두 선수의 경계를 즉시 갱신하며 순서·연속 충돌 판정·두 차례 체인 해소를 유지한다. 패스 길 예측은 최고 속도로 전체 비행 시간 내에도 닿을 수 없는 상대의 기여도0 계산만 생략한다.2,000개 충돌 배치와12,000개 패스/슈팅 경로를 기존 계산과 정확히 대조했다.

실제 파일 제공자가 내보내기를 마칠 때까지 준비 표시와 버튼 잠금을 유지한다. 창을 닫았다 다시 연 뒤 이전 작업이 끝나도 새 작업의 잠금을 풀지 않는다. 취소 문구와 실패 후 재시도를 유지하며, 실제 Android 문서 저장 검사도 내보내기 버튼을 누르는 경로로 보강했다. 실제 Android 검사에서 발견한 지연된 dialog close 이벤트는 닫을 때 세션을 즉시 정리하고, 이미 다시 열린 창에 이전 닫기 이벤트가 도착하면 무시하도록 고쳤다. 실제 브라우저에서 닫기 함수·직접 닫기·Escape 후 즉시 다시 여는 세 경우를 확인했다.

전술 분석의 기존 여섯 행에 공 뒤 인원을 표시한다. 골키퍼를 뺀 공과 자기 골문 사이 인원이며, 목표 배치와 현재 실제 위치를 구분한다. 보기만 해서는 경기·선발·난수·돈이 바뀌지 않는다. 연습 안내는 미리 정한 기회 생성 배율 대신 실제 이동과 위험을 설명한다.

다섯 시즌의 실제 저장에서 발견한 작은 가로 화면의 복귀 보고 잘림은 자동 높이와 두 열 배치로 고쳤다. 글자 크기와 선수 이름은 유지하고 복귀 상태는 초록색으로 구분한다.

## 검증 방법

전체 소스는 모든 검사를 별도 프로세스 두 개에 분산한다. 실패한 검사도 진단을 출력하고 나머지를 끝내며 실패 상태로 종료하는지 별도 대조한다. --jobs 1로 순차 실행도 가능하다. Source20분·Android 계측20분/전체45분 제한을 유지하며 검사나 판정을 생략하지 않는다.
