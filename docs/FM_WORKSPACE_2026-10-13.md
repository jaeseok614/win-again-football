# FM 모바일 참고: 선수단과 영입 비교

## 참고 자료

[FM24 Mobile 공식 소개](https://www.footballmanager.com/features/football-manager-2024-mobile-new-features-revealed)는 교체를 고를 때 능력·역할 적합도·컨디션을 비교하는 인터페이스와 선수단/전술 재구성을 설명한다. [공식 비교 화면](https://cdn.footballmanager.com/site/inline-images/Squad%20and%20Tactics%202.jpg)을 브라우저에서 직접 확인했다. [FM26 Mobile 공식 소개](https://www.footballmanager.com/fm26/features/football-manager-26-mobile-new-features-showcase)는 경기 준비와 코치 피드백의 확장을 설명한다. 화면 구성 원칙을 참고했고 원본 아트·코드·데이터는 가져오지 않았다.

## 실제 구현

- 전체 선수단: 가로740px 이상에서18명을 두 열로 표시. 등록 위치, 종합, 실제 남은 체력, 컨디션을 동시에 읽는다. 왼쪽에는 선택 선수의 얼굴/6능력 막대/상태, 아래에는44px 상세 보고서 버튼. 선수 선택은 미리보기만 바꾸며 상세 버튼으로 기존 전체 능력 보고서를 연다. 좁은568~640px에서는 이름과 정보를 유지하는 내부 목록 스크롤을 허용한다.
- 영입: 기본 목록·비교 보기. 필터 왼쪽, 후보8명 명단 중앙, 선택 후보 보고서 오른쪽. 현재 선수를 방출하는 실제 거래 기준으로 종합/속도/지구력/성장 한계를 비교하며 높은 값은 색상과 숫자로 표시. 선택한 선수의 실제 검토 버튼은 아래44px에 고정. 카드 보기로 전환 가능. 선택/보기 방식은 저장·RNG·재정·선발을 바꾸지 않는다.
- 이미 영입한 선수는 현재 훈련 능력/얼굴로 목록에 나타난다. 같은 포지션 방출 선수 변경, 관심 목록, 재정 검토, 실제 계약 확인은 기존 절차 재사용. 필터만으로 검색 가능하고 페이지가 바뀌면 존재하는 후보로 선택을 재정렬한다.
- 안내의 선수단 설명은 새 미리보기 흐름에 맞추고 두 번째 취임 장면에 토투넘 명칭을 복구. 이전 Android native 검사에서 빠진 구단명으로 해당1검사가 실패했음을 확인했고 문구를 고쳤다. 새 native 테스트는 선택 미리보기→명시적 상세 진입→뒤로가기→가이드 복귀를 모두 확인한다.

## 검증 상태

브라우저 fm-workspace.cjs:568×320,640×360,740×360,844×390,915×412,1024×768,1280×720에서 명단18명,740px이상 명단의 내부 스크롤 없음, 인물 identity, 미리보기/상세, 영입 선택/보기 전환/키워드 없는 필터, 저장 불변성 성공. 기존 가로 읽기7크기와 전술7크기×12포메이션 검사도 함께 실행. 자세한 최종 로컬/원격/네이티브 증거는 HANDOFF 최신 기록.

최종 PWA4,677,823바이트/shell e3778cb57ef6. 앞 가로 읽기 버전보다23,310바이트 추가. 새 네트워크 호출/추가 초상 비트맵 없음. 그림은 공유 atlas로 재사용. 실제 정보와 비교를 보강하며4,680,000바이트 모바일 상한 내 유지.

추가 native 시각 점검: 안내 버튼을 표시한 상태에서도 명단18명과6능력 표시를 확인하고, 영입의4개 핵심 비교 행이 고정 검토 버튼 위에 들어오는지 Chrome과 Android에서 직접 확인한다. Android 글꼴 차이로 발생한 내부 스크롤을 줄였다. 원격 Source38364667501도 c53 기능에 대해 전체/자산 일치 검증 성공했다.
