# 경기 준비 보고와 팀 훈련 비교

## 참고와 적용

- [FM24 Mobile 공식 기능](https://www.footballmanager.com/features/football-manager-2024-mobile-new-features-revealed): 경기 전 상대 전술/위험 선수/전력과 우리 선수 준비 상태를 모아 읽고 필요한 화면으로 이동하는 구조를 참고했습니다.
- [Top Eleven 공식 훈련 소개](https://www.topeleven.com/de/top-eleven-trainings/): 실행 전 능력 향상 예상과 체력 소모를 함께 확인하는 표시 방식을 참고했습니다.

이 게임의 실제 Season/Training/Staff/OwnerBoard/Opposition 결과를 사용합니다. 참고 게임의 수치·보너스·소스·상표 이미지·대사는 가져오지 않았습니다. 기존 원본 구단 규모 그림과 엠블렘을 재사용합니다.

## 구현

구단 현황 첫 화면에 현재 순위/승점/시즌 진행/주요 능력 평균/실제 출전 가능 인원/자금, 현재 상대의 실제 포메이션·요주의 선수·네 가지 전력 비교, 최근 확정 리그5결과를 함께 표시합니다. 선발 체력70미만, 계약2경기이내 만료, 훈련 공유잠금, 실제 신임/약속의 진행과 기한을 수석코치 준비 보고로 보여줍니다. 몸 상태/훈련/전술/경기 버튼은 하단44px 행으로 고정합니다. 경기 중 또는 결과 대기 상태는 해당 상태를 명시하고 아직 정산되지 않은 결과를 최근 확정 기록으로 넣지 않습니다.

팀 훈련에서는 기술/속도/지구력/회복을44px 버튼4개로 펼칩니다. 각각 실제 훈련예측의 능력/체력 변화 인원과 평균 체력 전후를 보여주며 선택만으로 실행하지 않습니다. 기존 실제 select와 onchange/실행 버튼 계약을 유지하고 한 화면 메뉴 안에서만 별도 비교 버튼을 보여줍니다. 실행은 원래 Season.train을 사용합니다.

실행이 성공했을 때만 실제18명 값의 훈련 직후 전후 결과를 표시합니다. 결과 표는 현재 앱 세션의 읽기 전용 메모리이며 저장된 훈련 이력이라고 주장하지 않습니다. 동일 캠페인/시즌/라운드/훈련 종류/등록 신원/실제 결과값이 맞을 때만 다시 표시합니다. 앱 재실행 또는 다른 주간에서는 현재 능력을 보여주며 과거 변화값을 만들지 않습니다. 팀/개인 주1회 공유, 코치 계약·성장한계·부상·실행 차단을 보존합니다.

## 검증 범위

source/test-preparation-desk.cjs는 현재 실시간 선발/상대와 읽기 불변성, 실제 네 훈련의 실행값과 예상값 일치(계약 코치 포함), 실제5리그경기 이후 코치 만료/최근 결과, 컵 상대/훈련 차단,46리그 종료 상태/다음 시즌 자동 전환 없음의5그룹과 실제 경기 중 교체·저장된 퇴장으로 인한 출전 불가의2그룹을 검사합니다. 현재 경기의 출전 가능 인원은 부상/정지뿐 아니라 이미 교체된 선수와 퇴장도 제외합니다.

기존8가로크기/10운영 페이지 내부 글자·이미지·조작 경계를 유지합니다. 새 훈련 비교 버튼의 실제 클릭, 실제18명 실행 전후 값과 결과 표, 준비 보고에서 훈련으로 왕복/공유잠금, 전체46R 종료 화면을 검사합니다. Android API34/35 기존14검사에 실제 비교 버튼·실행결과·준비페이지 왕복·종료보고 캡처를 추가했습니다. 모든 경계/시간 제한은 유지합니다. 최종 통과 커밋과 Source/Android/설치APK의 정확한 결과는 HANDOFF 완료 항목에 기록합니다.
