# 5부에서 시작하는 선수단 갈등

## 참고한 설계

[FM24 Console Dynamics 공식 소개](https://www.footballmanager.com/features/football-manager-2024-console-new-features-unveiled)의 성향별 반응·지각 처리·선수단 문화, [FM Supporter Confidence](https://www.footballmanager.com/features/supporter-confidence)의 팬과 구단을 보는 서로 다른 기대를 참고했습니다. 아래 사건과 대사는 토투넘을 위한 원본 허구이며 실제 선수 발언이 아닙니다.

## 네 갈래, 최대 열두 대화

|갈등|처음 열리는 때|내용|
|---|---|---|
|같은 자리, 다른 출전 시간|완전한 확정 리그 경기 2회 이후|실제 출전이 적은 선수와 같은 포지션에서 더 많이 뛴 선수의 충돌|
|훈련장 절반의 주인|리그 3경기 이후|지역 어린이 팀과 훈련장을 나눠 쓰며 드러나는 조급함과 동료에 대한 오해|
|출발 시각을 넘긴 버스|리그 9경기 이후|개인 사정으로 늦은 선수와 기다린 동료 사이의 공정성·사생활 갈등|
|문장보다 무거운 이름|리그 16경기 이후|강등에 상처받은 팬과 비난에 지친 선수의 언쟁|

각 갈래는 두 번 직접 답하는 최초 면담, 완료 후 리그 두 경기 뒤 재면담, 재면담 완료 후 두 경기 뒤 후일담으로 이어집니다. 시즌 밖에 일정을 만들지 않습니다. 5부 시즌에서만 새로 발생하고 승격한 뒤에도 과거 완료 대화는 읽을 수 있습니다.

출전 갈등은 최초 두 완전한 리그 기록으로 당사자를 고정합니다. 컵·진행 중·불완전한 기록은 제외합니다. 당사자 중 누군가 떠났다면 새 출전 갈등/아직 시작하지 않은 재면담은 만들지 않고, 기록한 대화는 보존합니다. 재면담에는 최초 면담 이후 두 리그 경기의 정확한 출전 시간을 표시합니다. 실제 기회를 준 경우와 계속 0분인 경우의 질문이 다릅니다.

중재 방식, 첫 면담의 두 번째 답, 재면담에서의 태도와 마무리 답을 다음 대화에서 기억합니다. 좋게 말했으니 즉시 화해했다고 처리하지 않습니다. 기존 관계 기록은 유지하고 갈등에 어울리지 않는 일반 충성도 칭찬 문구만 생략합니다. 자동 선발 변경·벌금·허구의 출전 약속 달성·능력치 보너스는 없습니다.

## UI와 검증

한 화면의 장면 → 질문 → 선택 후 반응 → 둘째 질문을 유지합니다. 320×568에서 긴 선택지에 본문 스크롤이 생기는 문제를 발견해 작은 세로 화면의 헤더를 줄였습니다. 확대 글꼴에서는 접근성용 본문 스크롤을 허용합니다.

새 회귀 7건은 5부 조건, 컵/불완전 기록 제외, 실제 같은 포지션·출전 시간, 선택 후 반응과 구단 불변, 저장 왕복·중복/위조 차단, 실제 선발 변경에 따른 재면담 분기, 세 단계 후일담, 실제 시즌 전환 후 과거 보존을 확인합니다. UI 검증은 사용자 원본 대신 별도 로컬 구단과 공개용 단일 번들을 사용했습니다. QA 파일은 저장소 밖에 둡니다.
