현재 구단
회사 컴퓨터에서는 기존 http://127.0.0.1:8765/ 주소에서 이어가세요.
상단 ‘저장·설치’ → ‘구단 저장 파일 받기’로 저장 파일을 받을 수 있습니다.
휴대폰으로 파일을 옮긴 뒤 온라인 게임의 ‘저장·설치’에서 파일을 선택하세요.
시즌·라운드·순위·승점·구단 자금을 먼저 확인하고 ‘이 구단으로 불러오기’를 누르세요.
확인하기 전에는 기존 구단이 바뀌지 않습니다. 교체 직전 구단은 현재 기기에 보관합니다.
‘직전 구단 미리보기’에서 확인하고 되돌릴 수 있습니다. 보관은 한 번만 하므로 내보낸 파일도 보관하세요.
경기 중 저장은 현재 분에 일시정지하고 불러옵니다. 경기 결과는 자동 확정하지 않습니다.
저장 파일은 2MB 이하의 이 게임 백업 형식만 지원합니다.
자동 기기 동기화는 없습니다. 옮길 때마다 새 저장 파일을 받아 불러오세요.

온라인 배포
GitHub 계정 jaeseok614의 win-again-football 공개 저장소에 배포할 파일을 준비했습니다.
예상 게임 주소: https://jaeseok614.github.io/win-again-football/
실제 GitHub Pages 배포 완료를 확인한 뒤 이 주소를 이용하세요.
휴대폰_v22_GitHub배포.zip에는 공개 정적 파일8개만 있습니다. 구단 저장 파일·QA·인증 정보는 포함하지 않습니다.
GitHub 저장소 root에8개 파일을 업로드한 뒤 Settings → Pages → Deploy from a branch → main / root → Save를 선택합니다.
배포된 인터넷 주소는 회사 컴퓨터를 꺼도 접속할 수 있습니다.

갤럭시 홈 화면 설치
1. 갤럭시 Chrome에서 배포된 게임 주소를 엽니다.
2. ⋮ 메뉴 → 설치 및 바로가기 만들기 → 설치. 버전에 따라 홈 화면에 추가로 표시됩니다.
3. 게임의 ‘저장·설치’에서 오프라인 준비 완료를 확인합니다.
4. 홈 화면 게임 아이콘으로 실행합니다. 최초 실행·업데이트에는 인터넷이 필요합니다.
브라우저 데이터 삭제나 기기 변경에 대비해 구단 저장 파일을 따로 보관하세요.
진동은 지원하는 기기와 브라우저에서 경기 설정을 켜면 작동합니다.

컴퓨터용 파일
이번엔_우승한다_휴대폰_v22.html은 이미지와 코드가 포함된 단일 실행 파일입니다.
Chrome 또는 Edge로 열면 게임 자체는 인터넷 없이 할 수 있습니다.
파일 실행과 인터넷 주소, 브라우저마다 저장 공간이 다르므로 저장 파일로 이동하세요.
