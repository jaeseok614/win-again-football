# 눈 떠보니 5부 리그 감독! 토투넘 1부 귀환기

약체 구단을 키워 승격과 우승에 도전하는 축구 감독 게임 시제품입니다.

게임 주소: https://jaeseok614.github.io/win-again-football/

갤럭시 Chrome에서 주소를 열고 메뉴의 설치 기능으로 홈 화면에 추가하세요.
저장·설치에서 구단 저장 파일을 받아 다른 기기에 불러올 수 있습니다.
저장은 기기마다 따로 유지되며 자동 동기화되지 않습니다.
오프라인 준비 완료 표시 후에는 같은 기기에서 인터넷 없이 실행할 수 있습니다.

가상 구단·선수와 자체 제작 이미지로 구성했습니다. 계정 로그인·광고·인앱 결제는 없습니다.
경기 중 전술·교체, 선수 훈련과 성장, 영입, 유소년, 리그 승격과 컵대회·챔피언스리그를 제공합니다.

기본 토투넘 18명은 서로 다른 원본 얼굴·주발·포지션·성격을 갖습니다.
선수 이름을 누르면 1–20 능력과 역할별 코치 리포트를 볼 수 있습니다.
영입에서는 이름을 몰라도 구단·나이·주발·역할·능력으로 32명 후보를 찾습니다.
선발·후보의 코치 제안에서 12개 포메이션의 배치를 비교한 뒤 직접 확정하세요.

중계는 점수·공·해설과 주요 버튼을 한 화면에 보여줍니다. 교체·전술·상대 분석은
팝업에서 열며 경기를 멈춥니다. 닫은 뒤 직접 이어가기 전까지 시간이 흐르지 않습니다.
경기 기록의 장면 다시 보기에서는 실제 공격을 당시 선수로 재구성합니다.
공격 경로 분석에서 크로스·컷백·침투·드리블 등의 실제 기회와 슈팅을 비교하고,
상대 분석의 선수 이름을 눌러 우리 선발과 능력을 비교할 수 있습니다.

처음 시작하면 이야기와 단계별 안내가 자동으로 나옵니다. 건너뛸 수 있으며,
설정의 처음 안내 다시 보기에서 언제든 다시 따라 할 수 있습니다.

경기 전·하프타임·65분에는 선수들에게 격려·칭찬·요구·안정을 선택해 말할 수 있습니다.
선수 성격·체력·스코어에 따라 실제 반응과 자신감이 달라지며 다음 경기 구간에 반영됩니다.
구단 메뉴의 인터뷰·기사에서 경기 전후 인터뷰와 실제 결과·득점·코치 영입 소식을 봅니다.
코치 후보와 계약에는 자체 제작한 가상 인물 얼굴을 표시합니다.

Google Play 출시용 Android 프로젝트는 `android/`에 있습니다. 인터넷 없이 게임을
실행하며 기존 웹 구단 저장을 파일로 가져올 수 있습니다. 아직 스토어에 등록되지 않았습니다.
개발자 계정 생성·앱 서명·테스트·스토어 등록 절차는 [출시 안내](docs/GOOGLE_PLAY_RELEASE.md)를 확인하세요.

휴대폰 메뉴·포지션 역할 추천 · 코치 계약과 구단 저장 보호

포지션 코치와 의무 코치는 선수단 → 선수 관리에서 관리합니다. 계약금·주급·
계약 기간을 확인하고 영입·연장·해지할 수 있으며 훈련과 의료에 실제 효과가 반영됩니다.
설치와 오프라인 준비에는 진행·완료·실패 안내를 표시합니다.

대회 메뉴에서 국내컵과 챔피언스리그를 확인합니다. 지난 시즌 1부 1~2위가
다음 시즌 유럽 대회에 출전하며, 조별 홈/원정 6경기 뒤 준결승·결승을 치릅니다.
대회 상금과 출전·득점·성장 기록을 실제 경기 결과에 맞춰 반영합니다.

## 개발 이어가기

[개발 안내](DEVELOPMENT.md)와 [개발 원칙](AGENTS.md)을 읽어 주세요. 다른 컴퓨터에서는 GitHub의 최신 `main`을 받아 이어가세요. 최신 모듈 소스·이미지·테스트는 source 폴더에 보관합니다. `node source/run-tests.cjs`로 전체 검증, `node source/build-pwa.cjs`로 공개 PWA를 빌드합니다. 원래 v22 ZIP은 과거 스냅샷이며 현재 코드나 폐기한 선수단을 복원하는 데 사용하지 않습니다. 개인 구단 저장 파일은 포함하지 않습니다.
